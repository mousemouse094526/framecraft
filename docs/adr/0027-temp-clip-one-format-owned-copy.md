# Temp clip ทุกคลิปเป็นสำเนา mp4 h264/aac ด้านสั้น ≤ 1080 ของแอปเอง ไม่ว่ามาจากไหน

Temp clip จากทุกแหล่ง (ลิงก์ทุกเว็บ หรือไฟล์ในเครื่อง) เป็นไฟล์ mp4 ภาพ h264 `yuv420p` เสียง aac ด้านสั้นไม่เกิน 1080 px ที่แอป copy มาเก็บใน `media/temp/` เอง. แอปไม่อ้างไฟล์ของผู้ใช้ที่เดิม และไม่แปลงไฟล์ตอนรับเข้า: แหล่งที่ไม่ตรงรูปแบบถูกปฏิเสธพร้อมบอกให้ผู้ใช้แปลงเอง. เพราะ player, Trim job (แทน mp4, ADR-0020), Whisper และ render ใช้ไฟล์รูปแบบเดียวทั้ง Mac และ Windows; อ้างไฟล์เดิมจะทำให้การตัดทำลายต้นฉบับ และผู้ใช้เลือกไม่ให้แอปแปลงไฟล์.

Source: spoil D5, D49, D54
