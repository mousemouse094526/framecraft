# Saved voice ผูกกับโมเดล TTS ที่สร้างมัน

Saved voice เก็บเป็น clone prompt ของ OmniVoice คู่กับความเร็วพูดที่วัดได้ จึงใช้ได้กับโมเดลนี้เท่านั้น. เปลี่ยนโมเดล TTS (ทางเดียวที่จะใช้เชิงพาณิชย์ได้ตาม ADR-0017) ทำให้ Saved voice และเสียงใน Spoil draft ทุกอันใช้ไม่ได้ ผู้ใช้ต้องออกแบบเสียงใหม่ แม้โค้ดส่วน TTS จะอยู่หลัง interface ที่เปลี่ยนได้. เลือกแบบนี้แทนชุดเสียงตายตัวจาก seed เพราะ seed เดียวกันอาจได้เสียงต่างกันข้ามเครื่อง.

Source: spoil-maker D3, D32, D35
