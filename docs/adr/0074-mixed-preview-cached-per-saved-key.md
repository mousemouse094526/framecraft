# เสียงตัวอย่างที่ backend ผสมเก็บไว้ต่อกุญแจของค่าที่บันทึกแล้ว

ปุ่มที่ฟังเสียงซึ่ง backend ผสม (`POST …/listen`) ใช้ `useListen` พร้อม `key` จากค่าที่บันทึกแล้วที่ backend อ่าน (ไม่ใช่ draft) กับธง `unsaved`: กุญแจเดิมและไม่มีอะไรค้างบันทึก = pause/เล่นต่อโดยไม่ขอใหม่, เปลี่ยนอะไรก็ตาม = หยุด แล้วกดครั้งต่อไปบันทึกและผสมใหม่. endpoint ฟังเสียงใหม่ทุกตัวต้องให้กุญแจแบบนี้ เพราะ backend ปรับรูปค่าหลังบันทึก กุญแจจาก draft จะทำให้ผสมใหม่ทุกครั้ง.
