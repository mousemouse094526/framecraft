# รองรับแค่ Mac Apple Silicon และ Windows NVIDIA

Project รองรับ Mac Apple Silicon (device `mps`) และ Windows ที่มีการ์ด NVIDIA (CUDA 12.8, device `cuda`) เท่านั้น. Linux, AMD GPU, Intel GPU และ Windows CPU-only ไม่อยู่ใน scope. ทุก feature ต้องทำงานและทดสอบบนทั้งสองแพลตฟอร์ม.

Source: setup-status D5

Status: superseded by ADR-0014
