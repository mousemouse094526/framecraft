# คลิปสอนกลองวาดกราฟิกด้วย Pillow ส่ง rgb24 เข้า ffmpeg ทาง stdin ตัวหนังสือทั้งหมดเป็น ASS

`frame_at(scene, t)` วาดทุกชิ้นที่ขยับจากเวลา t แล้วส่งผ่าน `ffmpeg.run_piped`; ของนิ่งวาดครั้งเดียวต่อ render และห้ามวาดตัวหนังสือด้วย Pillow เพราะภาษาไทยต้องใช้ shaping ของ libass. ไม่ใช้ filter หรือ ASS ล้วน (ไม้หมุนและเลนโน้ตเขียนยากและเทสไม่ได้), ไม่ใช้ browser headless (ต้องเพิ่ม browser เข้า Setup script) และไม่มีตัววาดในเบราว์เซอร์ (ต้องมีตัววาดสองชุดที่ต้องตรงกัน).

Source: video-gen D3, D18, D8
