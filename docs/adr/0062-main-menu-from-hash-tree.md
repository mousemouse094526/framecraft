# เมนูหลักอ่านจาก hash ผ่านต้นไม้ NAV ที่เดียว หน้าไม่บอกเมนูเอง

ทุกหน้าของแอปมีที่อยู่เป็น hash `#/…` ที่ไม่เปลี่ยนชื่อหรือหายไป และเมนูหลักหารายการที่เปิดอยู่จาก hash ปัจจุบันด้วยต้นไม้ `NAV` ใน `frontend/src/lib/nav.ts` เท่านั้น; หน้าใหม่ที่ควรอยู่ในเมนูเพิ่มรายการใน `NAV` ไม่ใช่ประกาศจากหน้าเอง. เพราะ bookmark กับลิงก์ข้ามหน้าพึ่ง hash ทุกตัว และการให้ 20+ หน้าบอกเมนูเองแก้หลายที่และลืมได้. หัวข้อใหญ่ของเมนูมีไม่เกิน 5–7 รายการ ส่วนที่เหลือเป็นรายการใต้หัวข้อ.
