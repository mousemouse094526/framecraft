# ไฟล์ mp4 ของ Temp clip ถูกแทนได้ด้วยการ encode ใหม่ ไม่มีต้นฉบับหรือแผนที่เวลา

การตัดช่วงทิ้งทำด้วยการ encode mp4 ใหม่แทนไฟล์เดิม ไม่เก็บต้นฉบับ และไม่เก็บว่าเวลาในไฟล์ตรงกับเวลาไหนบน YouTube: ทุกงาน (ถอด บรรยายฉาก ตัด EP render player) อ่านไฟล์เดียวและถือว่าเวลาในไฟล์คือเวลาของเนื้อหา. เลือกแทนการเก็บช่วงให้ทุกงานข้ามเอง (การแปลงเวลากระจายทุก feature พลาดที่เดียวก็ผิดเงียบๆ), stream copy (คลาดตาม keyframe) และการเก็บต้นฉบับ (ดิสก์ราวสองเท่า). ไฟล์จึงเปลี่ยนได้ระหว่างที่คลิปยังอยู่: ผู้ที่ cache หรือแสดงไฟล์ต้องผูกกับเวลาที่ตัดล่าสุด และการแทนไฟล์ที่ค้างตอน restart ทำต่อตอน start ครั้งหน้าแทนการทิ้ง (ต่างจากงานอื่นตาม ADR-0010).

**Status:** accepted

Source: spoil D36, D41
