# เมนูหลักไม่มี "ล่าสุด": มีแต่ลิงก์ตายตัวของ `NAV_SECTIONS`

เมนูหลักมีแต่ลิงก์ที่เขียนไว้ใน `NAV_SECTIONS` ของ `frontend/src/lib/nav.ts`: ไม่มีหมวดหรือลิงก์ที่มาจากสิ่งที่ผู้ใช้เปิดหรือทำ (ล่าสุด, ประวัติ, รายการโปรด) และหน้าไม่จำตัวเองไว้ให้เมนู. เพราะเจ้าของไม่ต้องการหมวดที่ซ้ำกับเมนูและทำให้งง; เมนู 2 ชั้นที่สั้นพาไปทุกหัวข้อใน 1 คลิกอยู่แล้ว และทางลัดไปชิ้นงานอยู่ในหน้าของหัวข้อนั้น. ทางลัดแบบนี้จะกลับมาได้ต่อเมื่อเจ้าของขอเอง.

**Status:** accepted
