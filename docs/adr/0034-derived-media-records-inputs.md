# ภาพและเสียงที่สร้างจากของต้นทางเก็บค่าต้นทางที่ใช้ และสถานะ "เก่า" คำนวณตอนอ่าน

ภาพการ์ดเก็บเลขรุ่นของภาพอ้างอิงที่ใช้ และเสียงเก็บข้อความกับ Saved voice ที่ใช้; เมื่อต้นทางเปลี่ยน แอปไม่ลบและไม่สร้างใหม่เอง แต่คำนวณสถานะเก่าตอนอ่านและให้ผู้ใช้เลือกสร้างใหม่. เลือกแบบนี้เพราะภาพละหลายนาทีบนเครื่องผู้ใช้ การลบหรือสร้างใหม่เองเสียงานที่อาจยังพอใช้ และการล็อกต้นทางทำให้แก้หน้าตัวละครไม่ได้. ต่างจากข้อมูลของ Temp clip ที่ตามไฟล์ปัจจุบันและถูกลบเมื่อไฟล์เปลี่ยน (ADR-0021).

Source: toon D32, D14 · spoil-maker D30
