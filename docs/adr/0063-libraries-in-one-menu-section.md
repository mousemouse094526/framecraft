# คลังทุกอันอยู่ในส่วน "คลัง" ของเมนูที่เดียว ไม่อยู่ใต้หัวข้อที่ใช้มัน

คลังคลิป คลังความรู้ คลังเสียง เสียงที่บันทึก และคลังใหม่ใด ๆ มีรายการเดียวในส่วน "คลัง" ท้ายเมนูหลัก พร้อมบรรทัด "ใช้กับ {หัวข้อ}". เพราะคลังใช้ร่วมหลายหัวข้อได้ (ADR-0037) และการวางใต้หัวข้อทำให้รายการซ้ำและ `aria-current` ไม่รู้ว่าอยู่ที่ไหน.

**Status:** superseded by ADR-0068
