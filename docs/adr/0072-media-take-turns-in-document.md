# media ใน document เล่นทีละตัวด้วย capture listener `play` ไม่ใช่ด้วยตัวเล่นแต่ละตัว

`<audio>`/`<video>` ใด ๆ ที่ไม่ `muted` เริ่มเล่น ทำให้ media อื่นที่เล่นอยู่และเครื่องเล่นเสียงหยุดชั่วคราว ผ่าน listener ตัวเดียวที่ `document`; ตัวเล่นวิดีโอไม่ต้องต่อสายอะไร. media ใหม่ต้องอยู่ใน document และไม่ `muted` จึงเข้ากฎ และต้อง `muted` ถ้าไม่ควรขัดเสียงอื่น. เพราะเจ้าของขอเล่นทีละเสียงทั้งแอปแต่ห้ามรื้อตัวเล่นวิดีโอ.
