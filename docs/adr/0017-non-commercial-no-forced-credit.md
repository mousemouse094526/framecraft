# ใช้แบบไม่หารายได้เท่านั้น แต่ไม่บังคับใส่เครดิตโมเดลในผลงาน

ผลงานที่ project สร้างใช้ส่วนตัวหรือทดลองเท่านั้น เพราะ OmniVoice เป็น CC BY-NC 4.0; `NOTICE.md` และหน้าสถานะยังแสดง license และ attribution ของโมเดล. flow ที่ export ผลงานไม่ใส่เครดิตโมเดลให้อัตโนมัติ: ผู้ใช้ใส่เองได้ (เช่นเป็นลายน้ำ) และรับความเสี่ยงเรื่อง attribution ไว้ เพราะจะเปลี่ยน TTS ก่อนใช้จริงจัง. จะใช้เชิงพาณิชย์ต้องเปลี่ยน TTS ก่อน; จะแจกจ่าย app ต้องเช็ค license ของ ffmpeg ใหม่.

**Status:** accepted — supersedes ADR-0007
