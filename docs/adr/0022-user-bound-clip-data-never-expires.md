# ข้อมูลที่ผู้ใช้ผูกกับคลิปลบพร้อมคลิป แต่ไม่หมดอายุเมื่อต้นทางเปลี่ยน

ข้อมูลที่อ้าง Temp clip มีสองแบบ: ที่คำนวณจาก mp4 (Transcript, Shot, การตัด EP, Spoil draft) หมดอายุตาม ADR-0021 ส่วนที่ผู้ใช้ผูกกับคลิปเอง (เช่น Story ที่คลิปจำ) อยู่จนลบคลิป ไม่หมดอายุเมื่อถอดใหม่ บรรยายฉากใหม่ หรือตัดช่วง. เลือกแบบนี้เพราะข้อมูลที่ผู้ใช้ผูกบอกว่าคลิปคืออะไร ไม่ได้มาจากไฟล์ จึงยังถูกหลังไฟล์เปลี่ยน และการให้เลือกใหม่ทุกครั้งที่ตัดช่วงเป็นงานซ้ำ. ข้อมูลแบบนี้ไม่อ่านไฟล์ของคลิปจึงไม่เข้าทะเบียน `clip_busy`; feature ใหม่ต้องบอกว่าข้อมูลของตัวเองเป็นแบบไหน.

Source: story-kb D7

**Status:** accepted — extends ADR-0021
