# ข้อมูลที่ได้จาก Temp clip เป็นของคลิปนั้น ไม่ว่า feature ไหนสร้าง

ทุกอย่างที่สร้างจาก Temp clip (Transcript, Shot, และงานของ feature อื่นที่อ้างคลิป) ถูกลบพร้อมคลิป และงานที่อ้างเลขบรรทัดหรือเลข Shot ของคลิปหมดอายุเมื่อคลิปถูกถอดหรือดูภาพใหม่: แอปเตือนและลบหลังผู้ใช้ยืนยัน. เลือกแบบนี้แทนการห้ามลบหรือการตัดเฉพาะส่วนที่อ้างคลิป เพราะไม่มีงานที่ชี้ข้อมูลผิดเงียบๆ และผู้ใช้เห็น flow เดียวทุกที่. feature ใหม่ที่เก็บข้อมูลอ้าง Temp clip ต้องต่อเข้ากับการลบและการทำใหม่ของคลิปด้วย.
