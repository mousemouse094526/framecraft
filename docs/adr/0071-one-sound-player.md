# เสียงทุกเสียงในแอปเล่นผ่านเครื่องเล่นเสียงตัวเดียว และเป็นของปุ่มที่เริ่มมัน

ทุกปุ่มที่เล่นเสียงเล่นผ่าน module `lib/player` ที่ถือ `HTMLAudioElement` ตัวเดียว อ่านด้วย `useSyncExternalStore` ไม่มี provider: เริ่มเสียงใหม่ = เสียงเดิมหยุด และเสียงหยุดเมื่อปุ่มเจ้าของหายไป เปลี่ยน src หรือกดไม่ได้. นอก module นี้ห้ามสร้าง `Audio` หรือเล่นเสียงทางอื่น. เพราะเจ้าของเจอเสียงจาก `playAudio` เล่นทับกัน และเสียงที่ไม่มีปุ่มบนจอหยุดไม่ได้.
