# ที่อยู่ของหน้าตามที่ในเมนู; hash เก่าทุกตัวพาไปหน้าใหม่

ทุก route อยู่ใต้ hash ของหัวข้อหรือคลังที่มันอยู่ในเมนูหลัก; ย้ายรายการในเมนูต้องย้าย route ด้วย ไม่ย้ายแค่ป้าย. เปลี่ยน hash ได้ต่อเมื่อ hash เก่าทุกตัวพาไปหน้าใหม่ผ่านตาราง `MOVED` ใน `frontend/src/lib/useHash.ts` ที่เดียว และโค้ดในแอปไม่ใช้ hash เก่าเอง. เพราะ `tabOf` เลือกหัวข้อจาก prefix ของ hash: ป้ายที่ย้ายโดยไม่ย้าย route ทำให้เมนูบอกที่ผิด และ bookmark กับ "ล่าสุด" ต้องไม่พัง.
