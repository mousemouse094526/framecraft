# แอปไม่มีบทเรียน: ทุกหน้ามีไว้ทำ reel ของที่ reel ใช้ หรือตั้งค่าเครื่อง

ทุกหน้า ปุ่ม ส่วน และคำบนจอ (รวม `aria-label` และ `message` ที่ backend ส่งให้หน้าเว็บโชว์) ต้องเดินไปถึงไฟล์คลิป เป็นของที่คลิปใช้ หรือตั้งค่าเครื่อง; อะไรที่สอน อธิบาย หรือสร้างบทเรียนโดยไม่ได้คลิปไม่อยู่ในแอป และเอาออกจริง ไม่ใช่ซ่อน. ขยายกฎเมนูของ ADR-0064 จากรายการเมนูไปทุกหน้า และเพราะการสร้างบทเรียนจากเพลงถูกลบ จึงแทน ADR-0047. เพราะเจ้าของบอกว่า "ไม่ได้จะทำบทเรียน" และอยากให้ "ใช้ง่ายไม่สับสน"; โค้ดที่ซ่อนไว้ยังต้องดูแล.

**Status:** accepted — supersedes ADR-0047, extends ADR-0064
