# ตัวละครและฉากหลังคงหน้าตาด้วยภาพอ้างอิงที่ส่งเข้าโมเดลพร้อมกันในรอบเดียว ไม่ฝึก LoRA ไม่ตัดพื้นไม่ซ้อนภาพ

ตัวละครหรือฉากหลังหนึ่งชิ้นมีภาพอ้างอิงหนึ่งภาพที่มีเลขรุ่น และภาพการ์ดสร้างครั้งเดียวโดยส่งภาพอ้างอิงของตัวละครในการ์ดกับฉากหลังของช่วงเข้า klein พร้อมกัน. เลือกแบบนี้เพราะผลลองคงหน้าตัวละครครบ 10 ภาพจากภาพเดียว, แสงในฉากตกบนตัวละครตามสไตล์ และไม่ต้องเพิ่มโมเดลตัดพื้นหรือฝึก LoRA ที่ยังไม่มีใครยืนยันบนเครื่อง 16 GB. เปลี่ยนไปใช้ LoRA หรือการซ้อนภาพต้องเปลี่ยนทั้งโมเดลและรูปข้อมูลของภาพการ์ด.

Source: toon D29, D31, D6
