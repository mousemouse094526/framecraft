# ข้อมูลที่ได้จาก Temp clip เป็นของไฟล์ mp4 ปัจจุบันของคลิป ไม่ว่า feature ไหนสร้าง

ทุกอย่างที่สร้างจาก Temp clip (Transcript, Shot, การตัด EP, Spoil draft และข้อมูลของ feature ใหม่ที่อ้างคลิป) ถูกลบพร้อมคลิป และหมดอายุเมื่อต้นทางเปลี่ยน — ถอดใหม่ บรรยายฉากใหม่ หรือตัดช่วง: แอปเตือน แล้วลบหลังผู้ใช้ยืนยันครั้งเดียว ไม่เลื่อนเวลาให้ตรง. เลือกแทนการห้ามลบ การตัดเฉพาะส่วนที่อ้างคลิป หรือการเลื่อนเวลา เพราะไม่มีงานที่ชี้ข้อมูลผิดเงียบๆ และผู้ใช้เห็น flow เดียวทุกที่; แก้ข้อความ Transcript ไม่เปลี่ยนเลขบรรทัดจึงไม่ทำให้อะไรหมดอายุ. งานที่อ่านไฟล์ของคลิปกับงานที่แทนไฟล์กันกันผ่านทะเบียนคลิปที่ถูกใช้ใน `backend.gpu` (`clip_busy`) และ feature ใหม่ที่เก็บข้อมูลอ้าง Temp clip ต้องต่อเข้ากับการลบ การทำใหม่ และทะเบียนนี้.

**Status:** accepted — supersedes ADR-0018; extended by ADR-0022
