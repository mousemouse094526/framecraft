# เสียงอย่างเดียวที่เอาเข้าถูกแปลงเป็น m4a รูปเดียวของแอป; ADR-0027 ครอบเฉพาะวิดีโอ

ไฟล์หรือลิงก์ที่เอาเข้าเป็นเสียงอย่างเดียว (คลังเสียงพื้นของ toon, Song ของแกะเพลง) ถูก ffmpeg แปลงเป็น aac ใน m4a รูปเดียวผ่าน `backend.audio_imports` ที่ใช้ร่วม; กฎสำเนาตรงไม่แปลงของ ADR-0027 ครอบเฉพาะ Temp clip ที่เป็นวิดีโอ. เพราะเสียงมาหลายรูปแบบ (mp3, m4a, webm) และต้องถอดเป็น PCM อยู่แล้ว ส่วนวิดีโอแปลงแล้วช้าและใหญ่. feature ต่อไปที่รับเสียงใช้ module นี้ ไม่เขียนทางของตัวเอง.

Source: drum-notes D4, D20 · toon D39
