# ก่อนหารายได้ต้องเปลี่ยนทั้ง TTS และตัวแกะกลอง เพราะ ADTOF เป็น CC BY-NC-SA

ADTOF Frame_RNN เป็น dependency แบบไม่หารายได้ตัวที่สองถัดจาก OmniVoice (ADR-0017): ใช้เป็นเครื่องมือวิเคราะห์ในเครื่อง ไม่แก้ ไม่แจกจ่ายไฟล์โมเดล และให้เครดิตผู้สร้างกับผู้แปลงใน `NOTICE.md` และหน้าสถานะ. รายการสิ่งที่ต้องเปลี่ยนก่อนใช้เชิงพาณิชย์จึงมีทั้ง TTS และตัวแกะกลอง (หรือตัดทางเสียงเหลือ MIDI). ยอมรับเพราะไม่มีโมเดลกลอง license เปิดที่ติดตั้งบน Python 3.12 ได้.

**Status:** accepted — extends ADR-0017
