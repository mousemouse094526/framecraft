# เสียงตัวอย่างที่ backend ผสมใช้ซ้ำจนฟอร์มถูกแก้

ปุ่มที่ฟังเสียงซึ่ง backend ผสม (`POST …/listen`) ใช้ `useListen` พร้อมธง `unsaved` ของฟอร์ม: ยังไม่มีอะไรค้างบันทึก = กดแล้ว pause/เล่นต่อ wav เดิมโดยไม่ขอใหม่, ฟอร์มถูกแก้ = เสียงหยุด แล้วกดครั้งต่อไปบันทึกและผสมใหม่. หน้าที่ใช้มันต้องเปิดฟอร์มใหม่ (remount) เมื่อของที่ backend ผสมจากเปลี่ยนโดยไม่ผ่านฟอร์ม เช่นแกะใหม่. เพราะเจ้าของขอให้ปุ่มฟังเป็น play/pause ไม่ผสมซ้ำ และกุญแจจากค่าที่บันทึกแข่งกับการบันทึกที่มาก่อนการผสม.
