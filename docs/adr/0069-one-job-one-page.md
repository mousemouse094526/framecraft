# งานหนึ่งชิ้นเป็นหน้าเดียว ขั้นของงานเป็นสถานะในหน้า ไม่ใช่ route

งานหนึ่งชิ้น (สปอย, เพลงหนึ่งเพลง, reel กลองหนึ่งชิ้น, EP หนึ่งตอน) เปิดที่ hash เดียว: เลือกของ ตั้งค่า และเห็นผล render ในหน้านั้น; ขั้นและ view เปลี่ยนในหน้า ไม่ลง history. route ใหม่มีได้เมื่อผู้ใช้เลือกของจริง (ชุด → EP, รายการ → ชิ้นงาน) เท่านั้น. เพราะขั้นที่เป็น route บังคับเดินหลายหน้าสำหรับงานชิ้นเดียว ซึ่งเจ้าของบอกว่า "ทำต้องเข้าหลายขั้น".
