# ทุกเสียงในคลังเสียงเป็นสำเนา m4a ของแอปที่แปลงตอนเอาเข้า

ไฟล์หรือลิงก์ที่ ffmpeg อ่านเสียงได้ถูกแปลงเป็น m4a (aac) รูปแบบเดียวตอนเอาเข้าคลัง และทุก render อ่านแค่รูปแบบนั้น. เลือกแบบนี้แทนการเก็บไฟล์เดิม เพื่อรับไฟล์ได้กว้างโดย render ไม่ต้องรองรับหลายรูปแบบ. ต่างจาก Temp clip ที่ไม่แปลง (ADR-0027) เพราะไม่มีใครเล่นหรือตัดไฟล์ต้นฉบับของเสียงพื้น.
