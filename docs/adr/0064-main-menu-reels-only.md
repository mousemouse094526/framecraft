# เมนูหลักมีเฉพาะทางที่ได้ reel ของที่ reel ใช้ หรือการตั้งค่าเครื่อง

แอปนี้ทำคลิปแนวตั้ง (reel) อย่างเดียว: รายการใหม่ใน `NAV_SECTIONS` ต้อง (ก) เดินต่อจนได้ไฟล์คลิปแนวตั้ง, (ข) เป็นคลังหรือของที่หน้าทำ reel อ่านไปใช้ หรือ (ค) ตั้งค่าเครื่องให้ทำ reel ได้ และอยู่ในหมวดของมัน (เล่าเรื่อง ดนตรี คลัง ตั้งค่า หรือหมวดใหม่ตามชนิด reel). หน้าที่สอนหรือสร้างบทเรียนโดยไม่ได้คลิปไม่อยู่ในเมนู; ไม่แน่ใจ = คงไว้และถามเจ้าของ. เพราะเจ้าของบอกว่าจุดประสงค์คือทำ reels เท่านั้น และเมนูคือสิ่งที่บอกว่าแอปทำอะไร.

**Status:** accepted — extended by ADR-0065, ADR-0070
