# feature ที่อ้างเสียงในคลังเสียงลงทะเบียนตัวเช็คพร้อม lock ของตัวเอง และเสียงที่ใช้อยู่ลบไม่ได้

ทุก feature ที่เก็บ `sound_id` ลงทะเบียนตัวเช็คกับ lock ของตัวเองและลำดับใน `backend.sounds`; การลบถือ lock ที่ลงทะเบียนตามลำดับก่อน lock ของคลัง แล้วตอบ `409` `in_use` เมื่อตัวเช็คใดบอกว่าใช้อยู่ และทุกที่ที่รับ `sound_id` เช็คว่าเสียงยังอยู่ขณะถือ lock ของตัวเอง. เลือกแบบนี้แทนการลบแล้วล้างที่อ้าง หรือให้คลังอ่านข้อมูลของ feature เอง เพื่อไม่ให้ EP หรือ draft ค้างกับเสียงที่หาย และลำดับ lock ข้าม feature เดียวกันทุกทางจึงไม่ deadlock. ขยาย ADR-0033 ของ Saved voice ไปที่คลังกลางตัวที่สอง; feature ใหม่ที่อ้างเสียงโดยไม่ลงทะเบียนทำให้กติกานี้พัง.

Source: sound-library D7, D11 · toon D25
