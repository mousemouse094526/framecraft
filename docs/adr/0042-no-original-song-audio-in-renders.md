# คลิปที่ render ไม่มีเสียงบันทึกของเพลงต้นฉบับ

เสียงเพลงที่ผู้ใช้เอาเข้ามา (ลิงก์หรือไฟล์) ใช้วิเคราะห์และฟังในแอปเท่านั้น; เสียงในคลิปสอนกลองทุกคลิปมาจาก sample กลองของแอป (ADR-0038, ADR-0039) ไม่มี backing track. เพราะคลิปที่เผยแพร่จะกลายเป็นการทำซ้ำสิ่งบันทึกเสียงที่ต้องขออนุญาตค่ายเพลง และเสียงสองทางขัด ADR-0038 (โน้ตชุดเดียวขับเสียงและภาพ). feature ต่อไปที่อยากใส่เพลงจริงในคลิปต้องตรวจ legal ใหม่และแทน ADR นี้.
