# เสียงบันทึกของเพลงต้นฉบับเข้าคลิปได้เฉพาะ reel cover ที่ผู้ใช้เปิด backing เองต่อ cover

backing ของ reel cover ปิดเป็นค่าตั้งต้น มีคำเตือนสิทธิ์ข้างตัวเลือก และผล render บันทึกว่าใช้ backing หรือไม่; ผู้ใช้ที่เปิดรับความเสี่ยงเรื่อง claim บล็อก หรือปิดเสียงเอง ส่วนคลิปสอนกลองยังไม่มี backing. เลือกแทนการไม่มี backing เลยเพราะเจ้าของขอให้มีทางเลือก และแทนการเปิดเป็นค่าตั้งต้นเพราะทุก reel จะโดน claim. backing ผสมเข้า wav ของ reel ทีเดียวหลังเสียงกลองที่มาจาก `timeline` และไม่กำหนดเวลาใด ๆ จึงไม่ขัดหลักโน้ตชุดเดียวของ ADR-0041.

**Status:** accepted — supersedes ADR-0045
