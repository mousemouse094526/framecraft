# reel cover หนึ่งชุดต่อเพลงเลือกเครื่องดนตรีด้วย `instrument` ไม่แยก cover ต่อเครื่องดนตรี

`cover.json` ของเพลงมี `instrument` (`drums` ตั้งต้น หรือ `kalimba`) กับช่วง ข้อความ พื้นหลัง และ backing ชุดเดียวที่ทุกเครื่องดนตรีใช้ร่วม; ความดังเก็บแยกในชื่อของเครื่องดนตรีนั้น และผล render บันทึก `instrument` โดยไฟล์เก่าอ่านเป็น `drums`. เลือกแทน cover แยกต่อเครื่องดนตรี เพราะต้องตั้งช่วงและข้อความสองครั้งสำหรับท่อนเดียวกัน และแทนการให้ `drums` เป็นความดังของเครื่องดนตรีที่เลือก เพราะอ่านไฟล์ผิด. เครื่องดนตรีถัดไปเพิ่มค่าใน `instrument` กับ block ความดังของตัวเอง ไม่สร้าง cover หรือ tab ใหม่.

**Status:** accepted — extends ADR-0052
