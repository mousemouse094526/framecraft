# เมนูหลักมี 2 ชั้นเท่านั้น: หมวด → ลิงก์ ไม่มีการกระทำ

ทุกบรรทัดใต้หัวหมวดใน `NAV_SECTIONS` เป็นลิงก์ไปที่ที่หนึ่ง: ไม่มีหัวกลุ่มซ้อนในหมวด ไม่มีบรรทัดที่เป็นการกระทำ ("สร้าง…") และไม่มีบรรทัดที่เปิดหน้าเดียวกับลิงก์อื่น; หน้าที่ลึกกว่าเปิดลิงก์ของมันด้วย prefix และการกระทำเป็นปุ่มในหน้า. เพราะเจ้าของงงกับชั้นซ้อน ("ทำไมต้องมีหมวดซ้อนหมวด") และเมนูคือที่ที่ไปได้ ไม่ใช่สิ่งที่ทำ.

**Status:** accepted

Source: nav-ia D16, D17
