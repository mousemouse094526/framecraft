# บทเรียนกลองที่สร้างจากเพลงเป็นสำเนาทางเดียว ไม่รู้จักเพลงต้นทาง

Song สร้างบทเรียนกลองผ่าน module `video_gen.lessons` ด้วยกฎตรวจเดียวกับ `PUT` แล้วจำ id บทเรียนไว้ฝั่งเพลง (กรองที่หายตอนอ่าน); `lesson.json` ไม่มี `song_id`, ลบเพลงไม่ลบบทเรียน, แกะใหม่ไม่แตะบทเรียน. ต่างจาก ADR-0021 และ ADR-0034 ที่ข้อมูลที่สร้างต่อตามต้นทาง เพราะบทเรียนเป็นงานที่ผู้ใช้แก้ต่อจนไม่เหลือร่องรอยของเพลง และ schema ของ video-gen ไม่ต้องแก้.

Source: drum-notes D2, D12, D18
