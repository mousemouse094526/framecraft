# ใช้แบบไม่หารายได้เท่านั้น เพราะ OmniVoice เป็น CC BY-NC

ผลงานที่ project สร้างใช้ส่วนตัวหรือทดลองเท่านั้น เพราะโมเดล OmniVoice ใช้ license CC BY-NC 4.0. ต้องมี attribution ของโมเดลใน `NOTICE.md` และหน้าสถานะ และ flow ที่ export หรือเผยแพร่ผลงานต้องใส่เครดิตโมเดล. จะใช้เชิงพาณิชย์ต้องเปลี่ยนโมเดล TTS ก่อน; จะแจกจ่าย app ต้องเช็ค license ของ ffmpeg ใหม่.

**Status:** superseded by ADR-0017
