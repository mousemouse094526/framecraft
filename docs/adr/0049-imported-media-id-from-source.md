# id ของสื่อที่เอาเข้ามาจากต้นทาง และของซ้ำชี้แถวเดิม

ทุกสื่อที่ผู้ใช้เอาเข้า (Temp clip, Song) มี id จากต้นทาง: ลิงก์ = เว็บ + id ของคลิป (YouTube 11 ตัวเดิม, เว็บอื่น `{extractor}-{id}`), ไฟล์ = `local-{sha1 ของชื่อ+ขนาด}`, ทั้งหมดตรง `[A-Za-z0-9_-]{1,64}`; ของซ้ำชี้แถวเดิมไม่โหลดใหม่และไม่เขียนทับ. เพราะ id เป็นชื่อ folder และอยู่ใน URL เปลี่ยนแล้วแถวเดิมหาย และ hash เนื้อหาต้องอ่านไฟล์ทั้งก้อนใน browser. feature ที่เอาสื่อเข้าใช้ `spoil.links` คำนวณ id ไม่คิดกฎเอง.
