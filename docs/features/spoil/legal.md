# Legal check: spoil

**Jurisdiction:** Thailand — checked 2026-10-29; ข้อ 4–5 checked 2026-10-29 (change request ถอดบทพูด); ข้อ 6 checked 2026-11-05 (change request ตัดช่วงคลิป); ข้อ 7–8 checked 2026-11-07 (change request หลายเว็บและไฟล์ในเครื่อง)

- ผู้ใช้โหลดหนังเต็มเรื่องที่คนอื่นปล่อยบน YouTube โดยไม่ได้รับอนุญาตจากเจ้าของลิขสิทธิ์ (D13)
- ปลายทางคือคลิปสปอยที่เผยแพร่และหารายได้ (D2, D13)
- รอบนี้ทำแค่โหลดเก็บในเครื่อง ไม่เผยแพร่อะไร (D2)
- ToS ของ YouTube เป็นสัญญากับ Google ใช้กฎหมาย California ไม่ใช่กฎหมายไทย

## 1. โหลดคลิป YouTube ของคนอื่นมาเก็บในเครื่องเพื่อทำคลิปหารายได้ (D2, D5, D13)

**Verdict: NOT ALLOWED**

การโหลดคือการทำซ้ำ ซึ่งเป็นสิทธิของเจ้าของลิขสิทธิ์แต่ผู้เดียว [1]. ข้อยกเว้น "ใช้เพื่อประโยชน์ของตนเอง" ใช้ได้เมื่อไม่ขัดการแสวงหาประโยชน์ตามปกติของเจ้าของ [1] ซึ่งการเอาไปทำคลิปหารายได้ไม่เข้า. ToS ของ YouTube ห้ามดาวน์โหลดเนื้อหาด้วย [3].

## 2. ใช้ yt-dlp แก้ JavaScript challenge ของ YouTube เพื่อโหลด (D8)

**Verdict: NOT ALLOWED**

ถ้า challenge นั้นนับเป็นมาตรการทางเทคโนโลยีที่ควบคุมการเข้าถึงงาน การหลบเลี่ยงโดยรู้ว่าอาจก่อให้เกิดการละเมิดลิขสิทธิ์เป็นการละเมิดตาม ม.53/4 [2] และข้อยกเว้น ม.53/5(1) ใช้ไม่ได้เพราะข้อ 1 ไม่ได้รับยกเว้น [2]. โทษปรับ 10,000–100,000 บาท; ทำเพื่อการค้าจำคุก 3 เดือนถึง 2 ปี หรือปรับ 50,000–400,000 บาท [2]. ToS ของ YouTube ห้ามหลีกเลี่ยงส่วนที่จำกัดการคัดลอกด้วย [3]. UNVERIFIED — from model knowledge, verify before relying: ยังไม่มีคำพิพากษาไทยที่ชี้ว่า JavaScript challenge ของ YouTube เป็นมาตรการทางเทคโนโลยีตามกฎหมาย.

## 3. ใช้เสียง OmniVoice ในคลิปที่หารายได้ (D13)

**Verdict: NOT ALLOWED**

license CC BY-NC 4.0 ห้ามใช้เพื่อประโยชน์ทางการค้า [4]. รอบนี้ไม่ใช้ OmniVoice; ต้องเปลี่ยน TTS ก่อน feature ใส่เสียงเล่า (ADR-0007).

## 4. ถอดบทพูดของหนังที่โหลดมาเป็นข้อความเก็บในเครื่อง เพื่อเขียนบทสปอยหารายได้ (D21, D23)

**Verdict: NOT ALLOWED**

บทพูดในหนังเป็นส่วนของงานอันมีลิขสิทธิ์ การถอดออกมาเป็นข้อความคือการทำซ้ำ ซึ่งเป็นสิทธิของเจ้าของแต่ผู้เดียว และข้อยกเว้นใช้เพื่อประโยชน์ของตนเองไม่ครอบคลุมเมื่อเอาไปทำงานหารายได้ [1] — เหตุผลเดียวกับข้อ 1. การเขียนบทสปอยใหม่ด้วยคำของผู้ใช้เองไม่ใช่การทำซ้ำ แต่การยกบทพูดยาวๆ ไปใส่คลิปเป็นการทำซ้ำ [1]. ผู้ใช้รับความเสี่ยงชุดนี้ไว้แล้วใน D13.

## 5. ใช้ Whisper large-v3-turbo ถอดเสียงในงานที่หารายได้ (D21)

**Verdict: ALLOWED**

โมเดลใช้ license MIT ที่อนุญาตใช้เชิงพาณิชย์ได้ โดยต้องคง copyright notice ไว้ [5] ซึ่ง `NOTICE.md` และหน้า Setup status มีอยู่แล้ว (setup-status D11).

## 6. ตัดช่วงออกจากหนังที่โหลดมาแล้วเก็บไฟล์ใหม่แทนในเครื่อง เพื่อทำคลิปสปอยหารายได้ (D36, D37)

**Verdict: NOT ALLOWED**

การตัดช่วงแล้ว encode ไฟล์ใหม่คือการทำซ้ำและดัดแปลงงาน ซึ่งเป็นสิทธิของเจ้าของลิขสิทธิ์แต่ผู้เดียว [1]. เป็นการทำกับสำเนาที่ได้จากข้อ 1 เพื่อปลายทางเดียวกัน ข้อยกเว้นเพื่อประโยชน์ของตนเองจึงใช้ไม่ได้ด้วยเหตุเดียวกับข้อ 1. ไม่มีการหลบเลี่ยงมาตรการทางเทคโนโลยีเพิ่ม และ encoder ทั้งสองมากับ ffmpeg ของ imageio-ffmpeg ที่ project ใช้อยู่แล้ว (ADR-0005) ไม่มี license ใหม่. ความเสี่ยงไม่เพิ่มจากข้อ 1: ไฟล์ใหม่สั้นกว่าเดิมและอยู่ในเครื่องเหมือนเดิม.

## 7. โหลดคลิปของคนอื่นจากเว็บอื่นนอก YouTube (Facebook, TikTok ฯลฯ) ด้วย yt-dlp เพื่อทำคลิปหารายได้ (D47)

**Verdict: NOT ALLOWED**

ลิขสิทธิ์เหมือนข้อ 1: การโหลดคือการทำซ้ำ และข้อยกเว้นเพื่อประโยชน์ของตนเองไม่ครอบคลุมงานหารายได้ [1]. เว็บใหญ่ห้ามเก็บเนื้อหาด้วยวิธีอัตโนมัติด้วย: Meta บอกว่า API ของ Platform เป็นทางเดียวที่เข้าถึงข้อมูลด้วยโปรแกรมได้ เว้นแต่ได้รับอนุญาตเป็นหนังสือ [6]; ToS ของ TikTok ห้ามดึงข้อมูลหรือเนื้อหาด้วยวิธีอัตโนมัติถ้าไม่ได้รับอนุมัติเป็นหนังสือ [7]. ถ้าเว็บมีมาตรการกันการคัดลอกและ yt-dlp หลบเลี่ยง ใช้เหตุผลของข้อ 2 (ม.53/4) [2]. แอปไม่ใช้ cookies และไม่โหลดคลิปที่ต้อง login (D47) จึงไม่เข้าถึงเนื้อหาที่ล็อกไว้. UNVERIFIED — from model knowledge, verify before relying: ข้อความ ToS ของ TikTok มาจาก tracker ที่ไม่ใช่เว็บของ TikTok เอง และไม่ได้เช็ค ToS ของเว็บอื่นทีละเว็บ.

## 8. copy ไฟล์ mp4 ที่ผู้ใช้มีในเครื่องเข้าแอป เพื่อถอด ตัด และทำคลิปสปอยหารายได้ (D49)

**Verdict: CONDITIONAL**

การ copy ไฟล์คือการทำซ้ำ [1]. งานของผู้ใช้เองหรืองานที่ได้รับอนุญาตให้ใช้ทำได้. งานของคนอื่นที่ไม่ได้รับอนุญาตเข้าเหตุผลเดียวกับข้อ 1 ไม่ว่าผู้ใช้ได้ไฟล์มาทางไหน [1]. แอปไม่หลบเลี่ยงมาตรการอะไรในข้อนี้: รับเฉพาะไฟล์ที่ ffmpeg อ่านได้ตรงๆ ไฟล์ที่มี DRM อ่านไม่ได้และได้ `unsupported_file`.

- ไฟล์เป็นงานของผู้ใช้เอง หรือผู้ใช้ได้รับอนุญาตจากเจ้าของลิขสิทธิ์ให้ทำซ้ำและดัดแปลงเพื่อทำคลิปหารายได้
- แอปไม่ถอด DRM หรือมาตรการกันคัดลอกของไฟล์ (ffmpeg ของ imageio อ่านไฟล์ที่เข้ารหัสไม่ได้ จึงเป็นอย่างนี้อยู่แล้ว)
