# คลิปสปอยตัวอย่างที่ผู้ใช้ให้มา

ผลวิเคราะห์คลิปสปอย 3 คลิปที่ผู้ใช้ส่งมาเป็นแบบ ใช้ตัดสินรูปแบบของ spoil-maker. วิเคราะห์ 2026-10-31 ด้วย yt-dlp, ffmpeg (นับจุดตัดภาพด้วย `select='gt(scene,0.3)'`) และ Whisper ของ project.

## สรุป

ทั้ง 3 คลิปใช้เสียงบรรยายเป็นแกน แล้ววางภาพจากต้นฉบับที่ตรงกับสิ่งที่ประโยคนั้นพูด. ต่างกันที่จังหวะตัด, layout และน้ำเสียง.

## สิ่งที่ spoil-maker ต้องทำได้ จากตัวอย่าง

- ทุกประโยคของบทบรรยายมีช่วงภาพจากต้นฉบับที่ตรงกับเนื้อหา ไม่ใช่แค่เรียงภาพตามเวลา
- บทของคลิปเล่าเรื่องยาวกว่าหนึ่ง EP ได้ (BLACKCASEFILE สรุปทั้งคดี) หรือแบ่งเป็นตอน (eed_closet "ตอนที่ 51(1)")
- ผลเป็นวิดีโอแนวตั้ง 1080×1920
- มีข้อความค้างบนจอได้: hook หรือชื่อตอน
