# Sketch: layout 3 แบบ

ร่างให้ผู้ใช้ดูก่อนตัดสินรายละเอียดของ layout (D8). เป็นภาพหยาบ ไม่ใช่แบบจริง. ทุกแบบได้วิดีโอ 1080×1920 และภาพต้นฉบับเป็น 16:9.

## A: เต็มจอ (แบบ Popcorn Pop)

```text
┌──────────────────────┐
│ ░░ ภาพเดิมเบลอ ░░░░░ │
│ ┏━━━━━━━━━━━━━━━━━━┓ │  ← hook 2 บรรทัด ค้างตลอดคลิป
│ ┃ มีใครจะคอแข็ง     ┃ │
│ ┃ เท่าเขามั้ย?      ┃ │
│ ┗━━━━━━━━━━━━━━━━━━┛ │
│ ┌──────────────────┐ │
│ │                  │ │  ← ภาพต้นฉบับ ครอปกลางเป็น 9:16
│ │   ภาพต้นฉบับ     │ │     (ขยายเต็มความสูง)
│ │                  │ │
│ │   «ซับท่อนสั้น»   │ │  ← ซับกลางจอ ตัวใหญ่ ขอบดำ
│ │                  │ │
│ └──────────────────┘ │
│ ░░ ภาพเดิมเบลอ ░░░░░ │
│        @ชื่อช่อง      │  ← watermark (ถ้าใส่)
└──────────────────────┘
```

## ส่วนประกอบที่ต้องตัดสิน

| ส่วน | A | B | C |
|---|---|---|---|
| ข้อความค้างด้านบน | hook | — | ชื่อตอน |
| ซับ | ท่อนสั้นกลางจอ | ประโยคใต้ภาพ | ไม่มี |
| ภาพต้นฉบับ | ครอป 9:16 บนพื้นเบลอ | 16:9 กลาง | 16:9 ช่วงบน |
| watermark | ได้ | ได้ | ได้ |

ข้อเท็จจริงที่ใช้: ffmpeg ใน `.venv` (imageio-ffmpeg 7.1) มี `libass`, `libharfbuzz`, `libfreetype` จึงวาดตัวไทยที่มีสระและวรรณยุกต์ซ้อนได้.
