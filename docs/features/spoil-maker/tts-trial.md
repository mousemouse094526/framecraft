# ลอง OmniVoice อ่านบทสปอยไทย

ลองบน Mac M2 RAM 16 GB เมื่อ 2026-10-31 เพื่อตอบ map: OmniVoice clone และเสียงตัวอย่าง. ใช้ `omnivoice` 0.2.1 กับโมเดล `k2-fsa/OmniVoice` (`c5fdb5c`) ที่ติดตั้งผ่าน Setup script แล้ว, torch 2.8.0, `device_map="mps"`, `dtype=float16`, `language="th"`. ไฟล์เสียงที่ได้อยู่ใน `media/spoil-maker-trial/` (ไม่อยู่ใน git).

## วิธีลอง

- บท: ประโยคสปอยไทย 6 ประโยค ยาว 40–80 ตัวอักษร (เรื่อง Night of the Living Dead) สร้างทีละประโยคตาม D30
- วัดว่าอ่านถูกไหม: ให้ Whisper (`whisper-large-v3-turbo` ของ project, float32) ถอดเสียงที่ได้กลับเป็นไทย แล้วนับ CER (ตัวอักษรที่ผิดต่อตัวอักษรทั้งหมด ไม่นับช่องว่างและวรรคตอน). เทียบกับเสียง Kanya ของ macOS อ่านประโยคเดียวกัน: CER 3–8%
- Whisper float16 บน MPS ถอดได้ `!` ทุกไฟล์: ต้องใช้ float32
- ไม่ได้ฟังด้วยหู: CER บอกว่าอ่านคำถูกไหม ไม่ได้บอกว่าเสียงเพราะหรือเป็นเสียงเดียวกันทุกประโยค

## เสียงที่มีให้เลือก

OmniVoice ไม่มีเสียงตัวอย่างสำเร็จรูป. มี 3 โหมด:

- **auto** — ไม่ใส่อะไร โมเดลเลือกเสียงเอง
- **voice design** — ใส่คุณสมบัติเป็นข้อความ `instruct`: เพศ (`male`, `female`), อายุ (`child` ถึง `elderly`), ระดับเสียง (`very low pitch` ถึง `very high pitch`), `whisper`, สำเนียงอังกฤษ. ผู้พัฒนาเขียนว่าฝึกด้วยข้อมูลจีนและอังกฤษเท่านั้น
- **clone** — ใส่ไฟล์เสียงกับข้อความที่พูดในไฟล์ (`ref_audio`, `ref_text`); เก็บเป็น prompt ไฟล์ `.pt` แล้วใช้ซ้ำได้ (`create_voice_clone_prompt`)

auto และ voice design สุ่มเสียงใหม่ทุกครั้งที่สร้าง จึงใช้ตรงๆ ไม่ได้กับ D6 ที่ต้องการเสียงเดิมทุกคลิป. ทางที่ลองแล้วได้: สร้างประโยคตัวอย่างหนึ่งประโยคด้วย voice design แล้วเก็บเป็น clone prompt ("เสียงล็อก") ใช้กับทุกประโยค.

| เสียงล็อกจาก voice design (ชาย, หญิง) | 4–7% | 17–20 วินาที | 13–15 |
| เสียงล็อก, `num_step` 16 | 4–7% | 9–10 วินาที | 13–15 |
| clone เสียงสะอาด (Kanya) 3 วินาที | 4–7% | 16–20 วินาที | 11 |
| clone เสียงสะอาด 6 วินาที | 5–7% | 17–19 วินาที | 11–12 |
| clone เสียงสะอาด 12 วินาที | 4–7% | 30 วินาที | 11–12 |
| clone เสียงสะอาด 21 วินาที | 8–17% | 46–48 วินาที | 11–12 |
| clone 6 วินาที, `ref_text` ผิดบางคำ | 5–8% | 18–20 วินาที | 11–12 |
| clone 6 วินาที, ใส่เสียงซ่า SNR 15 dB | 5–11% | 18–19 วินาที | 11–12 |
| clone คนจริง: ผู้บรรยายสารคดี `FT2UB-lBMQk` 6 วินาที | 3–8% | 20–21 วินาที | 12–14 |
| clone คนจริง: ผู้ให้สัมภาษณ์ข่าว `39qlIkfspBE` 3, 6, 7, 10, 26 วินาที | 71–558% | 13–56 วินาที | — |

- clone จากคลิปข่าวเสียทุกความยาว: คำผิดเกือบทั้งประโยค บางประโยควนคำเดิมซ้ำ (`แบบ แบบ แบบ …`). ไม่รู้สาเหตุแน่: ไฟล์นั้น Whisper เองก็ถอดหลอนตอนต้น (`โห โห โห …`) จึงน่าจะมีเสียงรบกวนหรือเสียงซ้อน. แปลว่าไฟล์ของผู้ใช้บางไฟล์ clone ไม่ได้ และดูจากความยาวไฟล์อย่างเดียวไม่รู้
- `ref_text` ผิดบางคำแทบไม่มีผล
- ไฟล์เสียงยาว 3–12 วินาทีให้ผลเท่ากัน ยาว 21 วินาทีอ่านผิดมากขึ้นและช้าลง 2.5 เท่า. ผู้พัฒนาแนะนำ 3–10 วินาที
- `num_step` 16 (ค่าเริ่มต้น 32) เร็วขึ้นเท่าตัว CER เท่าเดิม; ผู้ใช้ฟังแล้วไม่ต่าง (D37)
- float32 ไม่เร็วกว่า float16
- ตัวเลข: ดู รอบ 2. `normalize_text=True` สำหรับไทยใช้ `num2words` ซึ่งไม่ได้ติดตั้ง
- ความเร็วพูด 11–15 ตัวอักษรต่อวินาที เร็วกว่าคลิปตัวอย่าง (9–11, D7). `generate()` มี `speed` (น้อยกว่า 1 = ช้าลง, ดู รอบ 2) และ `duration` (กำหนดความยาว)

## รอบ 2: `speed` และตัวเลข

เสียงล็อกชายและหญิงจากรอบแรก, `num_step` 16, 3 ประโยคเดิม.

| `speed` | CER ชาย | ตัวอักษรต่อวินาที ชาย | CER หญิง | ตัวอักษรต่อวินาที หญิง | เวลาสร้างต่อประโยค |
|---|---|---|---|---|---|
| 0.8 | 3–9% | 10–11 | 4–8% | 12–14 | 9–11 วินาที |
| 0.9 | 4–9% | 11–12 | 4–5% | 13–15 | 8–10 วินาที |
| 1.0 | 4–7% | 12–14 | 4–5% | 15–16 | 8–9 วินาที |
| 1.2 | 4–8% | 14–16 | 4–8% | 17–19 | 8–9 วินาที |

- `speed` ไม่ทำให้อ่านผิดเพิ่ม และความเร็วพูดตาม `speed` เกือบเป็นสัดส่วน
- ความเร็วพูดต่างกันตามเสียง: ที่ `speed` เดียวกัน เสียงหญิงเร็วกว่าเสียงชายราว 15%
- ตัวเลข: ประโยค `ปี 1968 … 114,000 ดอลลาร์ … 30 ล้าน` อ่านผิดทั้งสองเสียง (`ปียาศกสปาด`, `หนึ่งสับบนทัน`). ประโยคเดียวกันที่เขียนเป็นคำ (`หนึ่งพันเก้าร้อยหกสิบแปด`) อ่านถูก: Whisper ถอดกลับได้ `1968`, `114,000`, `30 ล้าน`

## เวลาและ memory

- โหลดโมเดล 3 วินาที, memory MPS สูงสุดราว 3.5 GB (process ราว 3.7 GB)
- สร้าง clone prompt จากไฟล์ 10 วินาที 2.7 วินาที
- เสียงประโยคยาว 5–7 วินาที ใช้ 9–20 วินาที: ช้ากว่าเวลาจริง 2–3 เท่าบน M2 (ผู้พัฒนาวัด RTF 0.025 บน GPU NVIDIA)
- คลิปสปอย 60 วินาที ราว 12 ประโยค: เสียงล็อก `num_step` 32 ราว 4 นาที, 16 ราว 2 นาที

## สรุป

- OmniVoice อ่านไทยได้ดี: CER ใกล้กับ TTS ไทยของ macOS ทุกโหมดที่ไฟล์อ้างอิงดี
- "เสียงตัวอย่าง" ของ D6 ทำได้ด้วยเสียงล็อก: voice design หนึ่งประโยค เก็บเป็น prompt ใช้ซ้ำ
- clone ไฟล์ 3–10 วินาทีได้ แต่บางไฟล์ clone ไม่ได้: ผู้ใช้ต้องได้ฟังผลก่อนเก็บเสียง
- เขียนตัวเลขเป็นคำแล้วอ่านถูก เขียนเป็นตัวเลขอ่านผิด
- ใช้ memory น้อยกว่า LLM (D13) มาก แต่ยังเป็นงาน GPU ทีละงาน (ADR-0012)

## ยังไม่ได้ลอง

- `duration` กับเสียงที่ดี
- ไฟล์เสียงที่ผู้ใช้อัดเองด้วยไมค์
- Windows: ทำใน `windows-check` (ADR-0014)
