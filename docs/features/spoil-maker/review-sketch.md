# Sketch: ตรวจแก้ก่อน render

ร่างให้ผู้ใช้ดูก่อนตัดสินขั้นตรวจแก้ (map: ตรวจแก้ก่อน render). เป็นภาพหยาบ ไม่ใช่แบบจริง.

## ขั้นของการทำคลิปสปอยหนึ่งคลิป

| ขั้น | ใครทำ | ได้อะไร | เวลาโดยประมาณ (หนัง 96 นาที) |
|---|---|---|---|
| 1. ตั้งค่า | ผู้ใช้ | Temp clip ที่เรียงแล้ว (D5), สไตล์และความยาว (D7), layout (D8) | — |
| 2. ร่างบท | LLM ขั้นแรก (D18) | ประโยค, บรรทัด Transcript ที่อ้าง, hook หรือชื่อตอน (D19) | ราว 5 นาที |
| 3. เลือก Shot | LLM ขั้นสอง (D18) | 2 Shot ต่อประโยค | ราว 5 วินาทีต่อประโยค |
| 4. ตรวจแก้ | ผู้ใช้ | บทและ Shot ที่แก้แล้ว | — |
| 5. สร้างเสียง | OmniVoice (D6) | เสียงต่อประโยค | ยังไม่ได้วัด |
| 6. render | ffmpeg | mp4 กับ `.srt` (D10) | ยังไม่ได้วัด |

## หน้าตรวจแก้

```text
┌───────────────────────────────────────────────────────────────┐
│ hook: [ มีใครจะคอแข็งเท่าเขามั้ย?                       ]    │
│ ความยาวประมาณ 58 / 60 วินาที · 9 ประโยค                       │
├───────────────────────────────────────────────────────────────┤
│ 1 ┌──────┐┌──────┐  [ ชายคนหนึ่งตื่นมาในห้องที่ไม่รู้จัก   ]  │
│   │ shot ││ shot │  อ้าง: EP1 00:01:12 "Where am I?"            │
│   │ 0:58 ││ 1:04 │  เสียง: ✓ 3.4 วิ  [▶ ฟัง] [สร้างเสียงใหม่]  │
│   └──────┘└──────┘                                             │
├───────────────────────────────────────────────────────────────┤
│ 2 ┌──────┐┌──────┐  [ เขาพบจดหมายที่เขียนด้วยลายมือตัวเอง ]  │
│   │  ?   ││  ?   │  อ้าง: — (AI อ้างบรรทัดไม่ได้)              │
│   │เลือก ││เลือก │  เสียง: ยังไม่สร้าง                          │
│   └──────┘└──────┘                                             │
├───────────────────────────────────────────────────────────────┤
│ …                                                             │
├───────────────────────────────────────────────────────────────┤
│                       [สร้างเสียงทั้งหมด]  [render]            │
└───────────────────────────────────────────────────────────────┘
```

- กดภาพ Shot → เปิดตัวเลือก Shot (ด้านล่าง)
- แก้ข้อความของประโยคที่มีเสียงแล้ว → เสียงของประโยคนั้นเป็น "ต้องสร้างใหม่"
- ประโยคที่อ้างบรรทัดไม่ได้ไม่มี Shot ให้ตั้งต้น (D18) ผู้ใช้ต้องเลือกเองก่อน render

## ตัวเลือก Shot

```text
┌──────────────────────────────────────────────────┐
│ เลือกภาพให้ประโยค 2                  [ปิด]      │
│ ช่วง: ±30 วิรอบบรรทัดที่อ้าง  [ดูทั้งคลิป ▾ EP1] │
│ ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐            │
│ │0:31││0:35││0:41││0:44││0:52││0:58│ ...        │
│ └────┘└────┘└────┘└────┘└────┘└────┘            │
│ Shot description ของภาพที่ชี้อยู่                  │
│ [▶ เล่นช่วงนี้]                                    │
└──────────────────────────────────────────────────┘
```

## สถานะของแต่ละประโยค

| สถานะ | ความหมาย | render ได้ไหม |
|---|---|---|
| ไม่มี Shot | อ้างบรรทัดไม่ได้และผู้ใช้ยังไม่เลือก | ไม่ได้ |
| ยังไม่มีเสียง | ยังไม่ได้สร้างเสียง | สร้างให้ตอน render |
| ต้องสร้างเสียงใหม่ | แก้ข้อความหลังสร้างเสียง | สร้างให้ตอน render |
| พร้อม | มี Shot และเสียงตรงข้อความ | ได้ |
