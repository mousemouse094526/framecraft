# Spec: nav-ia

เมนู route และทางทำงานของแต่ละหัวข้อจัดใหม่ทั้งชุด: ที่อยู่ตรงกับที่ในเมนู และงานหนึ่งชิ้นเป็นพื้นที่ทำงานเดียว.

**Status:** ready-to-build

## Problem

เจ้าของบอกว่า "route และ menu ต่างดูแปลกๆมาก ... menu ไหนควรอยู่อันไหน แล้วการทำงานแต่ละ menu ก็มีความแปลกเหมือนกัน ทำต้องเข้าหลายขั้น". ui-nav เปลี่ยนแค่ป้ายกับที่วางในเมนูโดยไม่แตะ route (ui-nav D6) ชื่อกับที่อยู่จึงไม่ตรงกัน และขั้นของแต่ละงาน (สปอย 3 ขั้น, เพลง → reel, reel กลอง → ผล render, EP → render) เป็นหน้าแยกที่ต้องเดินต่อกัน.

## Solution

- ทุกหน้าอยู่ใต้ hash ของที่มันอยู่ในเมนู (D1); hash เก่าทุกตัวพาไปหน้าใหม่ (D9).
- คลิปของสปอยอยู่ใต้หัวข้อสปอย หมวดคลังเหลือของอ้างอิง (D2, D3); เสียงพากย์มีที่อยู่ของตัวเอง (D4).
- สปอยเป็นพื้นที่ทำงานเดียวที่ขั้นเป็นสถานะในหน้า (D5).
- เพลงหนึ่งเพลงมีแกะโน้ตกับ reel cover ในหน้าเดียว ใต้หัวข้อ "reel cover" (D6).
- reel กลองหนึ่งชิ้นมีผล render ในหน้าเดียวกับฟอร์ม (D7).
- EP การ์ตูนเล่ามี พล็อต · เส้นเรื่อง · render ในหน้าเดียว (D8).
- เมนูมี 2 ชั้นเท่านั้น หมวด → ลิงก์ (D16); ไม่มีการกระทำหรือบรรทัดที่ซ้ำหน้า (D17); ล่าสุดเป็นหมวดของตัวเอง (D18); หัวหน้าคือชื่อลิงก์ที่เปิด หน้าลึกกว่าใช้ชื่อลิงก์แหล่ง (D19, D20).

## User Stories

**เจ้าของ (คนทำ reel)**
1. As เจ้าของ, I want ชื่อในเมนูกับที่อยู่ของหน้าตรงกัน, so that เปิดหน้าไหนก็รู้ว่าอยู่หัวข้อไหน (D1)
2. As เจ้าของ, I want โหลดและถอดคลิปจากหัวข้อสปอย, so that เตรียมของของสปอยอยู่ที่เดียวกับที่ทำสปอย (D2)
3. As เจ้าของ, I want เปิดสปอยแล้วอยู่ที่งานที่ค้าง ข้ามขั้นได้ในหน้าเดียว, so that ไม่ต้องเดิน 3 หน้าต่อกัน (D5)
4. As เจ้าของ, I want เปิดเพลงแล้วทำ reel cover ต่อในหน้าเดียว, so that ไม่ต้องหาการ์ด Reel cover แล้วเปิดอีกหน้า (D6)
5. As เจ้าของ, I want render reel กลองแล้วเห็นผลใต้ฟอร์ม, so that แก้แล้ว render ใหม่ได้โดยไม่สลับหน้า (D7)
6. As เจ้าของ, I want สลับพล็อต เส้นเรื่อง และ render ของ EP ในหน้าเดียว, so that EP หนึ่งตอนเป็นที่ทำงานเดียว (D8)
7. As เจ้าของ, I want bookmark และ "ล่าสุด" เดิมยังพาไปหน้าที่ถูก, so that ไม่มีลิงก์พัง (D9)
8. As เจ้าของ, I want เมนูที่ทุกบรรทัดใต้หัวหมวดเป็นที่ที่กดไปได้ ไม่มีชั้นซ้อนและไม่มีบรรทัดซ้ำความหมาย, so that ไม่งงว่าอะไรซ้อนอยู่ใต้อะไร (D16–D20)

## Design

ทุกจอใช้ component และ token เดิม (D11, D16). ตารางนี้คือภาพเดียวของโครงสร้างใหม่: เมนู ↔ route ↔ งานที่ทำได้.

| หมวด | ลิงก์ในเมนู › (หน้าลึกกว่า) | route | งานที่ทำได้ | ทำไมอยู่ที่นี่ |
|---|---|---|---|---|
| เล่าเรื่อง | ทำสปอย | `#/spoil` | ขั้นในหน้า: เลือกคลิป (EP, Story, ตั้งค่า, ร่างบท) · ตรวจแก้บท (ประโยค ภาพ เสียงเล่า เสียงพื้น render) · ผล render (ดู โหลด ลบ) | งานชิ้นเดียว ขั้นเป็นสถานะ (D5) |
| เล่าเรื่อง | คลิปทั้งหมด | `#/spoil/clips` | โหลดคลิปจากลิงก์หรือไฟล์ ตัดช่วง ถอดบทพูด บรรยายฉาก แก้ Transcript | วัตถุดิบของสปอยหัวข้อเดียว (D2) |
| เล่าเรื่อง | การ์ตูนเล่า (prefix, D16) | `#/toon` | รายการชุด ลบชุด ปุ่ม "สร้าง Series" | เหมือนเดิม |
| เล่าเรื่อง | การ์ตูนเล่า › (สร้างชุด) | `#/toon/new` | ตั้งค่าชุดใหม่ เปิดจากปุ่มในหน้า ไม่มีบรรทัดในเมนู | การกระทำ ไม่ใช่ที่ (D17) |
| เล่าเรื่อง | การ์ตูนเล่า › (หน้าของชุด) | `#/toon/series/{id}` `/cast` `/settings` `/{kind}/{id}/pick` | EP ของชุด, ตัวละครและฉากหลัง, ตั้งค่าชุด, เลือกภาพอ้างอิง | ชุด → EP คือการเลือกของ (D8) |
| เล่าเรื่อง | การ์ตูนเล่า › (หน้า EP) | `#/toon/eps/{id}` | สถานะในหน้า: พล็อต · เส้นเรื่อง · render | งานชิ้นเดียว (D8) |
| ดนตรี | reel cover (prefix, D16) | `#/covers` | เพิ่มเพลงจากลิงก์ ไฟล์เสียง หรือ MIDI ลบเพลง | วัตถุดิบของ reel cover (D2, D6) |
| ดนตรี | reel cover › (หน้าเพลง) | `#/covers/{id}` | ช่วงแกะ แกะโน้ต → reel กลองหรือคาลิมบา ช่วง ข้อความ เสียง ฟัง render ผล render | งานชิ้นเดียว (D6) |
| ดนตรี | reel กลอง (prefix, D16) | `#/drums` | สร้าง ทำซ้ำ ลบ reel | เหมือนเดิม |
| ดนตรี | reel กลอง › (หน้า reel) | `#/drums/{id}` | หัวเรื่อง Groove BPM พื้นหลัง รอบ ฟังจังหวะ render ผล render | งานชิ้นเดียว (D7) |
| คลัง | คลังความรู้ (ใช้กับ สปอย) | `#/stories` `/new` `/{id}` | เขียน แก้ ลบ Story | ของอ้างอิง (D3) |
| คลัง | คลังเสียง (ใช้กับ สปอย, การ์ตูนเล่า) | `#/sounds` (`?back=`) | เพิ่ม ฟัง ลบเสียงพื้น | ของใช้ร่วม (ADR-0037) |
| คลัง | เสียงพากย์ (ใช้กับ สปอย, การ์ตูนเล่า) | `#/voices` | ออกแบบ ฟัง บันทึก เปลี่ยนชื่อ ลบ Saved voice | ของใช้ร่วม (D4) |
| ตั้งค่า | ติดตั้ง | `#/setup` (hash ว่างหรือไม่รู้จัก) | Setup status | เหมือนเดิม |

ไม่มีชื่อสปอยหรือชั้นหัวข้อในเมนู: สปอยเหลือแค่ในชื่อลิงก์ "ทำสปอย" (D16). หมวด "ล่าสุด" อยู่ระหว่างดนตรีกับคลัง (D18): ลิงก์ล่าสุดของ การ์ตูนเล่า → reel cover → reel กลอง (≤3 ต่อแหล่ง ที่เก็บเดิม ui-nav D5) ของ reel cover เป็น `#/covers/{id}`; ไม่มีของล่าสุดเลย = ไม่มีหมวดนี้.

### ชั้นของเมนู

เมนูมี 2 ชั้น: หัวหมวด แล้วลิงก์ (D16). หน้าตาของทั้งสองชั้นคือของเดิม ไม่มีเยื้อง ไม่มี token ใหม่.

| ชั้น | อะไร | หน้าตา |
|---|---|---|
| 1 หมวด | เล่าเรื่อง · ดนตรี · ล่าสุด · คลัง · ตั้งค่า | `MenuSection` เดิม: 11px `font-semibold` `muted-foreground`, เส้น `border` คั่นด้านบน (ui-nav D12) |
| 2 ลิงก์ | ทุกบรรทัดใต้หมวด | `MenuLink` เดิม; บรรทัดรองเล็กใต้ชื่อ (แบบ "ใช้กับ …") มีในคลัง และในล่าสุดซึ่งบอกแหล่ง ("การ์ตูนเล่า", "reel cover", "reel กลอง") |

ก่อน → หลัง:

| หมวด | ก่อน | หลัง |
|---|---|---|
| เล่าเรื่อง | หัวกลุ่ม สปอย › ทำสปอย · คลิปทั้งหมด; หัวกลุ่ม การ์ตูนเล่า › ชุดทั้งหมด · สร้างชุดใหม่ · ล่าสุด | ทำสปอย · คลิปทั้งหมด · การ์ตูนเล่า |
| ดนตรี | หัวกลุ่ม reel cover › เพลงทั้งหมด · ล่าสุด; หัวกลุ่ม reel กลอง › reel ทั้งหมด · ล่าสุด | reel cover · reel กลอง |
| ล่าสุด | — (อยู่ใต้หัวกลุ่ม) | ล่าสุดของทั้งสามแหล่ง พร้อมบรรทัดรองบอกแหล่ง |
| คลัง | คลังความรู้ · คลังเสียง · เสียงพากย์ | เหมือนเดิม |
| ตั้งค่า | ติดตั้ง | เหมือนเดิม |

ตัวอย่างเมนูเมื่อมีล่าสุด:

```text
เล่าเรื่อง
  ทำสปอย
  คลิปทั้งหมด
  การ์ตูนเล่า
ดนตรี
  reel cover
  reel กลอง
ล่าสุด
  EP 3: ไปทะเล        การ์ตูนเล่า
  Smells Like Teen Spirit   reel cover
คลัง
  คลังความรู้          ใช้กับ สปอย
  คลังเสียง            ใช้กับ สปอย, การ์ตูนเล่า
  เสียงพากย์           ใช้กับ สปอย, การ์ตูนเล่า
ตั้งค่า
  ติดตั้ง
```

### หัวหน้าและลิงก์ที่เปิด

ลิงก์ที่เปิดคือลิงก์ที่ hash ยาวที่สุดที่เปิดที่ hash นี้ (ui-nav D6, D11) ในลิงก์ที่เป็นของ tab ที่เปิดอยู่ (`tabOf`): ลิงก์ของหัวข้อนั้นกับล่าสุดของมัน, ลิงก์ของคลังเมื่อ tab เป็น `stories` `sounds` `voices`, ติดตั้งเมื่อ tab เป็น `setup`. hash ที่ `tabOf` ไม่รู้จัก (เช่น `#/toon?x` ซึ่งเปิดหน้าติดตั้ง) จึงไม่ทำให้ลิงก์อื่นเปิด. `<h1>` ตาม D19, D20:

| hash | ลิงก์ `aria-current="page"` | `<h1>` |
|---|---|---|
| `#/spoil` | ทำสปอย | ทำสปอย |
| `#/spoil/clips` | คลิปทั้งหมด | คลิปทั้งหมด |
| `#/toon`, `#/toon/new`, `#/toon/…` ที่ไม่มีในล่าสุด | การ์ตูนเล่า | การ์ตูนเล่า |
| `#/toon/series/{id}…` `#/toon/eps/{id}` ที่มีในล่าสุด | ลิงก์นั้นในล่าสุด | การ์ตูนเล่า |
| `#/covers`, `#/covers/{id}` ที่ไม่มีในล่าสุด | reel cover | reel cover |
| `#/covers/{id}` ที่มีในล่าสุด | ลิงก์นั้นในล่าสุด | reel cover |
| `#/drums`, `#/drums/{id}` ที่ไม่มีในล่าสุด | reel กลอง | reel กลอง |
| `#/drums/{id}` ที่มีในล่าสุด | ลิงก์นั้นในล่าสุด | reel กลอง |
| `#/stories…`, `#/sounds…`, `#/voices` | ลิงก์ในคลัง | คลังความรู้ / คลังเสียง / เสียงพากย์ |
| `#/setup`, hash ว่างหรือไม่รู้จัก | ติดตั้ง | ติดตั้ง |

`<h1>` จึงไม่เปลี่ยนตอนหน้ารายละเอียดเพิ่มตัวเองเข้าล่าสุดหลังโหลด; ที่เปลี่ยนคือลิงก์ที่เปิดย้ายไปที่ลิงก์ล่าสุดของหน้านั้น (D20). ปุ่ม ☰ อ่าน "เมนู: {`<h1>`}" เหมือนเดิม.

ล่าสุดเรียงตามแหล่งด้วยค่าคงที่ `["toon", "covers", "drums"]` ไม่ใช่ลำดับกุญแจของที่เก็บ (D18). ชื่อในล่าสุดเป็นชื่อที่เก็บไว้ (ตัดที่ 80 ตัวอักษร, `recent.ts`). สองชิ้นชื่อเดียวกัน (EP 1 ของสองชุด) หรือชิ้นที่ชื่อเท่าลิงก์ในเมนู เห็นเป็นสองบรรทัดชื่อเดียวกันได้: ยอมรับ ไม่เก็บชื่อชุดเพิ่ม.

## Expected Outcome

เจ้าของเปิดหัวข้อใดก็ทำงานชิ้นหนึ่งจนได้ reel ในหน้าเดียว และที่อยู่บอกว่าอยู่ตรงไหนของเมนูเสมอ.
- **เปิด `#/spoil` เมื่อมีบทค้าง:** เห็นแถบขั้นที่ขั้นตรวจแก้บทเลือกอยู่ และบท; กด "ผล render" เห็นผลโดยที่อยู่ยังเป็น `#/spoil`.
- **เปิด bookmark `#/songs/abc/cover`:** ที่อยู่กลายเป็น `#/covers/abc` และเห็นหน้าเพลงที่มีส่วน reel.
- **เปิด `#/voices`:** หัวหน้าบอก "เสียงพากย์" และลิงก์เสียงพากย์ในคลังเป็นลิงก์ที่เปิด.
- **เปิดเมนูที่ใดก็ได้:** ใต้หัวหมวดมีแต่ลิงก์ ไม่มีหัวกลุ่ม; ดนตรีมีสองลิงก์ reel cover กับ reel กลอง; กด reel กลอง → `#/drums` หัวหน้าบอก "reel กลอง"; เปิดเพลงจากล่าสุด → ลิงก์เพลงนั้นในล่าสุดเปิด หัวหน้ายังบอก "reel cover".

**How success is judged:**
- เมนูมีลิงก์ตาม Design › ชั้นของเมนู ตามลำดับนี้ ไม่มีรายการขั้นของสปอย ไม่มีกลุ่มใต้หมวด
- hash เก่าทุกแถวในตาราง Redirect เปิดหน้าใหม่ของมัน และ `location.hash` เป็น hash ใหม่
- ไม่มี route `#/spoil/review`, `#/spoil/renders`, `#/songs/…`, `#/drums/{id}/renders`, `#/toon/eps/{id}/plot`, `#/toon/eps/{id}/render` ที่เปิดหน้าของตัวเอง
- ทุกความสามารถในตาราง Design ทำได้ (test เดิมของหน้าเหล่านั้นผ่านหลังแก้ hash)

### Redirect

`MOVED` ทำงานตอนอ่าน hash ทุกครั้ง (โหลดหน้าและ `hashchange`) ด้วย `replaceState` แบบเดิม (D9). ลำดับ: แถวแรกที่ตรงชนะ.

| hash เก่า | hash ใหม่ |
|---|---|
| `#/toon/sounds` | `#/sounds` (เดิม) |
| `#/clips` | `#/spoil/clips` |
| `#/spoil/voices` | `#/voices` |
| `#/spoil/review` | `#/spoil` |
| `#/spoil/renders` | `#/spoil` |
| `#/songs` | `#/covers` |
| `#/songs/{id}` | `#/covers/{id}` |
| `#/songs/{id}/cover` | `#/covers/{id}` |
| `#/drums/{id}/renders` | `#/drums/{id}` |
| `#/toon/eps/{id}/plot` | `#/toon/eps/{id}` |
| `#/toon/eps/{id}/render` | `#/toon/eps/{id}` |

`{id}` รับตัวอักษรเดียวกับที่ parser ของหน้านั้นรับ (`[A-Za-z0-9_-]{1,64}`, reel กลอง `[a-z0-9]{12}`).

## Seams

`App` กับหน้าใน jsdom ตามแบบที่มีอยู่ (D12).

1. **เมนูและ route** `App` ใน jsdom
   - render ที่ hash ใดก็ได้ → เมนูมีลิงก์ตาม Design › ชั้นของเมนู ตามลำดับ พร้อม "ใช้กับ …" ของคลัง
   - hash ของแต่ละแถว Design › หัวหน้าและลิงก์ที่เปิด → ลิงก์ที่ `aria-current="page"` และ `<h1>` ตรงกับแถวนั้น
   - hash เก่าแต่ละแถว Redirect → `location.hash` เป็น hash ใหม่ และหน้าใหม่ขึ้น
   - ล่าสุดที่เก็บ `songs: [{hash: "#/songs/x"}]` → หมวดล่าสุดมีลิงก์ `#/covers/x` บรรทัดรอง "reel cover"
2. **พื้นที่ทำงานสปอย** `SpoilMakerPage` ใน jsdom
   - ไม่มี draft → ขั้นเลือกคลิปเปิด; มี draft → ตรวจแก้บทเปิด; กดผล render → เห็นผล `location.hash` ยังเป็น `#/spoil`
   - ร่างบทเริ่ม → ตรวจแก้บทเปิด; render เสร็จขณะตรวจแก้บทเปิด → ผล render เปิด; ยกเลิกร่าง → เลือกคลิปเปิด
   - ปุ่ม "ไปที่ตรวจแก้บท" และ "ไปที่ตั้งค่าคลิปสปอย" → เปลี่ยนขั้น; กดขั้นระหว่างกำลังโหลด → ขั้นที่กดคงอยู่หลังโหลดเสร็จ
3. **หน้างานชิ้นเดียว** `SongsPage` (ผ่าน `App`), `DrumsPage`, `ToonPage` ใน jsdom — หนึ่ง `it` ขึ้นไปต่อหน้า
   - เพลงที่แกะแล้ว → หน้าเดียวมีผลแกะ ปุ่ม "ไปที่ reel" และส่วน reel (ฟัง render ผล render) ทำงานเหมือนหน้า reel เดิม; เพลงที่ยังไม่แกะ → ไม่มีส่วน reel
   - แกะใหม่ขณะ reel ยังไม่บันทึก → ถาม "ออกโดยไม่บันทึก?"; ตอบไม่ → ไม่แกะ; แกะเสร็จ → ส่วน reel อ่าน cover ใหม่
   - หน้า reel กลองมีผล render; render ที่หน้านี้เริ่มเสร็จ → ผลใหม่ขึ้น `scrollIntoView` ถูกเรียกที่ส่วนผล hash ไม่เปลี่ยน
   - EP ที่มีการ์ด → เส้นเรื่องเปิด; EP ที่ยังเป็นพล็อต → พล็อตเปิด ไม่มี render; สลับพล็อตและ render ได้ hash ยังเป็น `#/toon/eps/{id}`; แตกการ์ดเสร็จขณะพล็อตเปิด → เส้นเรื่องเปิด

4. **เมนู 2 ชั้น** `App` ใน jsdom (D16–D20)
   - ไม่มีล่าสุด → กลุ่มในเมนูคือหมวด เล่าเรื่อง · ดนตรี · คลัง · ตั้งค่า เท่านั้น (ไม่มีกลุ่มซ้อนในหมวด); ลิงก์ตามลำดับคือ ทำสปอย · คลิปทั้งหมด · การ์ตูนเล่า · reel cover · reel กลอง · คลังความรู้ · คลังเสียง · เสียงพากย์ · ติดตั้ง
   - มีล่าสุดของ reel กลอง reel cover และการ์ตูนเล่า (เก็บไว้ในลำดับ toon → drums → covers) → หมวด "ล่าสุด" อยู่ระหว่างดนตรีกับคลัง ลิงก์เรียง การ์ตูนเล่า → reel cover → reel กลอง แต่ละลิงก์มีคำอธิบาย (`aria-describedby`) เป็นชื่อแหล่ง
   - เปิด hash ของลิงก์ล่าสุด → ลิงก์นั้น `aria-current="page"` ลิงก์แหล่งไม่ใช่ และ `<h1>` เป็นชื่อแหล่งตรงตัว (D20)
   - `#/toon?x` → หน้าติดตั้ง ลิงก์ติดตั้งเปิด ลิงก์การ์ตูนเล่าไม่เปิด
   - ไม่มีลิงก์ "สร้างชุดใหม่" "ชุดทั้งหมด" "เพลงทั้งหมด" "reel ทั้งหมด"; `#/toon/new` → ลิงก์การ์ตูนเล่าเปิด
