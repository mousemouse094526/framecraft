- ไม่มีสองชิ้นทับกัน: ระยะศูนย์กลางของทุกคู่ > ผลรวมรัศมี × 1.2 (ขนาดตอนขยายของ accent) และทุกชิ้นตอนขยายอยู่ใน x 54–1026, y 400–1090 — test ตรวจตารางนี้ และหัวไม้ที่ที่พักของทั้งสองมือ
- ตอนพัก: เติมสีชิ้น 30 % ขอบสีชิ้น 5 px
- ตอนตี (0.15 วิ หลังการตี, `FADE_STEPS` ขั้นแบบเดิม): เติมสีชิ้น 100 % ขอบขาว 8 px ขยาย 1.12 เท่าแล้วหดกลับเชิงเส้น; accent ขยาย 1.2 เท่า; ghost เติม 60 %
- `hihat_open` ตอนตี: วงขาวบางรอบนอก (รัศมี 1.25) บอกว่าเปิด
- ป้ายชื่อ: ASS ตัวหนา 30 px สีขาว ขอบดำ 3 px ศูนย์กลางของป้ายที่ (cx, cy − 0.55 r) ครึ่งบนของชิ้น ตลอดคลิป (`PEDAL` 22 px) — ไม่ทับจุดตีและหัวไม้
- **จุดตี** (strike) = (cx, cy + 0.35 r) ครึ่งล่างของชิ้น ฝั่งด้ามไม้; ไม้และหัวไม้ไปถึงแค่ตรงนั้น
- **จุดวัดสี** (probe) = (cx, cy − 0.1 r): ระหว่างป้ายกับจุดตี ไม่มีป้าย หัวไม้ หรือป้ายมือทับตอนการตีเดี่ยว — test เสียงตรงภาพและ test เฟรมอ่านสีที่จุดนี้
- ป้ายมือตอนตี: วงกลมรัศมี 22 สีของมือ ที่ (ศูนย์กลาง + รัศมี × (0.7, −0.7)) ตัว L/R ดำ 26 px ใน ASS แสดง 0.15 วิ; เท้า (`kick`, `hihat_pedal`) ไม่มีป้ายมือ

## เลนโน้ต

- กรอบ x 54–1026, y 1180–1600; คอลัมน์ชื่อ x 54–200 (ชื่อชิ้นสีของชิ้น ASS ตัวหนา 26 px ชิดซ้าย); เลน x 210–1026; playhead ขาว 4 px ที่ x 330
- เลน = ชิ้นที่มีอย่างน้อยหนึ่งการตีใน reel เรียงตาม `crash, ride, hihat_open, hihat_closed, tom_high, tom_mid, snare, tom_floor, hihat_pedal, kick`; `hihat_open` กับ `hihat_closed` แยกเลน (ชื่อ `HH OPEN`, `HI-HAT`)
- ความสูงแถว = `min(84, 420 / จำนวนเลน)`; เส้นกลางแถวสี `#2A3A50` 2 px
- ความเร็ว: กว้างเลน 816 px = 1.5 ห้องที่ `bpm` ของ Lesson ชั่วคราว (แบบ video-gen `WINDOW_BARS`); ปลายคลิป (หางเสียง 1.5 วิ) เลนหยุดนิ่งที่เวลาจบช่วง
- หัวโน้ต เส้นผ่านศูนย์กลาง = 0.7 × ความสูงแถว สีของชิ้น:

| ชิ้น | รูป |
|---|---|
| `snare`, `tom_high`, `tom_mid`, `tom_floor` | วงกลมทึบ |
| `kick` | วงกลมทึบ 1.15 เท่า |
| `hihat_closed` | X หนา |
| `hihat_open` | X ในวงกลมขอบ |
| `crash`, `ride` | สี่เหลี่ยมข้าวหลามตัดทึบ |
| `hihat_pedal` | X 0.7 เท่า |

- accent: 1.25 เท่า ขอบขาว 3 px; ghost: 0.8 เท่า จาง 50 %; ตอนผ่าน playhead (0.15 วิ) เรืองขาวรอบ (แบบ video-gen `GLOW_S`)
- ตัว L/R ในหัวโน้ตของมือ: ASS 0.55 × ความสูงแถว สีของมือ ขอบดำ 2 px เลื่อนด้วย `\move` ไปกับหัวโน้ต (แบบเลขจังหวะของ video-gen); เท้าและ `hand` `null` ไม่มีตัวอักษร
- เส้นจังหวะจาง 1 px; เส้นห้องขาว 40 % 3 px มีเลขห้องเล็ก (ASS 22 px) เหนือกรอบเลน

## ตัวนับ

- มุมขวาบน ชิดขวาที่ x 1026: "ห้อง {n}" ASS ตัวหนา 52 px ที่ y 250; จุดจังหวะ 4 จุด รัศมี 12 ห่าง 36 ใต้ข้อความที่ y 345 (จุดของจังหวะที่กำลังเล่นขาวเต็ม ที่เหลือขาว 25 %)
- `n` = ลำดับ downbeat ที่ผ่านมาในคลิป เริ่ม 1; ก่อน downbeat แรกของคลิป → แสดงแค่จุด ไม่มี "ห้อง"
- ห้อง 3/4 (จังหวะในห้องน้อยกว่า 4) → จำนวนจุด = จำนวนจังหวะของห้องนั้น (สูงสุด 4)
- เลขจังหวะ > 4 (ห้องยาวหรือ downbeat หาย, `timeline` นับต่อ 5, 6, …) → จุดที่ 4 สว่าง
- หัวเรื่องและบรรทัดรองของ reel กว้างไม่เกิน 760 px (บีบ `\fscx` แบบ video-gen D22; บรรทัดรอง 30 ตัวต่อบรรทัด) เพื่อไม่ชนคอลัมน์ตัวนับ x 830–1026
