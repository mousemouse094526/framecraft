# Legal check: video-gen

**Jurisdiction:** Thailand — checked 2026-11-13

- แอปทำงานในเครื่องผู้ใช้คนเดียว ไม่มี server ไม่เก็บข้อมูลส่วนบุคคลของใคร: ไม่มีเรื่อง PDPA ให้ตรวจ
- ผู้ใช้เป็นคนเผยแพร่คลิปเองบน Facebook และ TikTok แอปจบที่ไฟล์ mp4 (D10, D14)
- ตอนนี้คลิปไม่หารายได้ อาจหารายได้ทีหลัง; ข้อ 2 แยกผลของการหารายได้ไว้
- เสียงของคลิปเป็นกลองที่แอปผสมจาก sample อย่างเดียว ไม่มีเสียงเพลงต้นฉบับ (D2, D7)
- font Kanit ตรวจแล้วใน [spoil-maker legal.md](../spoil-maker/legal.md) ข้อ 4 ไม่ตรวจซ้ำ

## 1. ใช้ sample กลอง Karoryfer Big Rusty Drums (CC0 1.0) ในเสียงของคลิปที่เผยแพร่ (D11)

**Verdict: ALLOWED** [2][3]

## 2. ถอดโน้ตกลองช่วงสั้นของเพลงที่มีลิขสิทธิ์ เล่นด้วยกลองสังเคราะห์ แสดงชื่อเพลงและศิลปิน แล้วเผยแพร่เป็นคลิปสอน (D2, D4, D12)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- ใช้เพียงช่วงสั้นของเพลง เช่น fill หรือ groove ไม่กี่ห้อง ไม่ใช่ส่วนกลองของทั้งเพลง [1]
- ไม่ใส่ทำนอง คำร้อง หรือเสียงบันทึกของเพลงต้นฉบับในคลิป [1]
- คลิปเป็นการสอนหรืออธิบายส่วนกลอง ด้วยท่อนสอนและคำอธิบายของผู้ใช้เอง [1]
- ระบุชื่อเพลงและชื่อศิลปินบนจอหรือในคำอธิบายคลิป เป็นการรับรู้ความเป็นเจ้าของลิขสิทธิ์ [1][4]
- ใช้ชื่อศิลปินเพื่อบอกว่าเป็นเพลงของใคร ไม่ใช้โลโก้ของวง และไม่ทำให้คนดูเข้าใจว่าวงหรือค่ายเพลงสนับสนุนคลิป [5]
- ก่อนเริ่มหารายได้จากคลิปแบบนี้ ตรวจข้อนี้ใหม่หรือขออนุญาตเจ้าของลิขสิทธิ์: ข้อยกเว้นเพื่อการสอนตามมาตรา 32 (6) ใช้ได้เฉพาะที่ไม่หากำไร [1]

เพลงที่เป็นตัวอย่างใน spec (Smells Like Teen Spirit, 1991) ยังมีลิขสิทธิ์: อายุคุ้มครองคือตลอดชีวิตผู้สร้างสรรค์บวก 50 ปี [1]. การบรรเลงส่วนหนึ่งของดนตรีกรรมแล้วเผยแพร่เป็นสิทธิของเจ้าของแต่ผู้เดียว [1]; ทนายไทยตอบว่าการ cover เพลงลงโซเชียลต้องขออนุญาต [4]. คลิปจึงพึ่งข้อยกเว้นมาตรา 32 และ 33: ใช้บางตอนตามสมควร รับรู้ความเป็นเจ้าของ ไม่ขัดการแสวงหาประโยชน์ตามปกติของเจ้าของ [1]. เมื่อหารายได้ เหลือแค่มาตรา 33 กับวรรคหนึ่งของมาตรา 32 ซึ่งอ่อนกว่า.

ชื่อเพลงและชื่อวงบนจอไม่ใช่การใช้เครื่องหมายการค้า: เครื่องหมายการค้าคือเครื่องหมายที่ใช้กับสินค้าเพื่อแยกสินค้าของเจ้าของจากของคนอื่น และสิทธิแต่ผู้เดียวครอบคลุมการใช้กับสินค้าที่จดทะเบียนไว้ [5].

UNVERIFIED — from model knowledge, verify before relying: ยังไม่พบคำพิพากษาหรือแนวทางของกรมทรัพย์สินทางปัญญาที่ชี้ว่าโน้ตกลองไม่กี่ห้องโดยไม่มีทำนองเป็น "ส่วนอันเป็นสาระสำคัญ" ของดนตรีกรรมหรือไม่ และคลิปสอนบนเพจส่วนตัวเข้ามาตรา 32 (6) ที่เขียนถึง "ผู้สอน" หรือไม่.

## 3. ใช้ภาพจากไฟล์ของผู้ใช้เป็นพื้นหลังคลิป (D6)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- ภาพเป็นของผู้ใช้เอง หรือ license อนุญาตให้ใช้ในวิดีโอที่เผยแพร่ (เช่น CC0): ภาพถ่ายและภาพวาดเป็นศิลปกรรมที่มีลิขสิทธิ์ และการทำซ้ำแล้วเผยแพร่เป็นสิทธิของเจ้าของแต่ผู้เดียว [1]
- ไม่ใช้ปกอัลบั้มแบบคลิปอ้างอิงโดยไม่ได้รับอนุญาต: ภาพที่ครอป เบลอ และทำมืดยังเป็นการทำซ้ำภาพนั้น [1]
- หน้าแก้บทเรียนบอกผู้ใช้สองข้อนี้ข้างปุ่มเลือกภาพ

UNVERIFIED — from model knowledge, verify before relying: ไม่พบแหล่งไทยที่ชี้ว่าปกอัลบั้มที่เบลอจนจำแทบไม่ได้เข้าข้อยกเว้นมาตรา 32 หรือ 33.

## 4. เลียนแบบหน้าตาคลิปของเพจ Your Turn: การจัดวาง สี และตำแหน่งของชิ้นบนจอ โดยไม่ copy ไฟล์ของเขา (D12, D13)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- วาดทุกชิ้นบนจอเองด้วยโค้ดของแอป (ไดอะแกรมชุดกลอง ไม้ หัวโน้ต) ไม่ trace หรือ copy ภาพ ไอคอน หรือไฟล์กราฟิกจากเฟรมของเขา: ลิขสิทธิ์ไม่คุ้มครองความคิด วิธีการ หรือระบบ แต่คุ้มครองงานศิลปกรรมที่เขาวาด [1]
- ไม่ใส่ชื่อเพจ โลโก้ หรือลายน้ำของเพจในคลิปหรือคำอธิบาย ในทางที่ทำให้คนดูเชื่อว่าคลิปมาจากเพจนั้น [5]

ป้ายท่อนค่าตั้งต้นเป็น `ลองเล่นเอง` (spec › Data, D23) ใช้เป็นคำสั่งให้คนดูเล่นตาม ไม่ใช่ชื่อผู้ทำคลิป; `YOUR TURN.` ของคลิปอ้างอิงไม่ได้ใช้เพราะอาจเป็นเครื่องหมายการค้าของเพจนั้น (D23).
