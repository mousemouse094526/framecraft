# Sketch: ช่องในการ์ด

ร่างให้ตัดสินว่าการ์ดหนึ่งใบมีช่องอะไร ใครเติม และเป็นตัวเลือกตายตัวหรือข้อความอิสระ. ไม่ใช่แบบหน้าจอ.

## ช่องของการ์ด

| ช่อง | ใครเติม | แบบ | หมายเหตุ |
|---|---|---|---|
| ข้อความเล่า | AI ร่าง ผู้ใช้แก้ | ข้อความอิสระ ว่างได้ | ว่าง = การ์ดเงียบ (D14) |
| ฉากหลัง | มาจากช่วง | — | ไม่ใช่ช่องของการ์ด (D9) |
| ตัวละครในภาพ | AI เลือก ผู้ใช้แก้ | เลือกจากตัวละครใน Series, 0 ถึงสูงสุด N ตัว | N รอผลลอง klein (สองตัวปนหน้ากันไหม) |
| คำบรรยายภาพ | AI ร่าง ผู้ใช้แก้ | ดูคำถามด้านล่าง | ท่าทาง สีหน้า มุมกล้อง แสง |
| การขยับ | AI เสนอ ผู้ใช้เลือก | นิ่ง / ซูมเข้า / ซูมออก / เลื่อนซ้าย / เลื่อนขวา | D4 |
| ไฟกะพริบ | AI เสนอ ผู้ใช้เปิดปิด | เปิด / ปิด | D4 |
| วินาทีค้างเพิ่ม | ผู้ใช้ | 0–5 วินาที ทีละ 0.5 | ตั้งต้น 0; การ์ดเงียบตั้งต้น 2 (D14) |
| เสียงเล่า | ปุ่ม | สร้าง / ฟัง / สร้างใหม่ทีละการ์ด | แบบ spoil-maker D30; แก้ข้อความ = ต้องสร้างใหม่ |
| ภาพการ์ด | ปุ่ม | สร้าง / ดู | ข้อ "หลายภาพให้เลือก" ยังเปิดอยู่ |
| ป้าย "แก้เอง" | แอป | อัตโนมัติ | D15 |

ช่วงเว้นท้ายเสียงเล่าไม่มีช่อง: ค่าตายตัวของแอป.

## สองแบบของคำบรรยายภาพ

**แบบ A — ข้อความอิสระช่องเดียว**

```
คำบรรยายภาพ: รุ่นพี่นั่งหน้ากองไฟ หน้าซีด มองไปทางป่ามืด มุมกว้าง แสงไฟส้มจากล่าง
```

**แบบ B — แยกช่อง ตัวเลือกตายตัว + ข้อความสั้น**

```
สีหน้า:    [กลัว ▾]        (ปกติ / ยิ้ม / กลัว / ตกใจ / เศร้า / โกรธ)
มุมกล้อง:  [มุมกว้าง ▾]    (ใกล้หน้า / ครึ่งตัว / มุมกว้าง)
แสง:       [ไฟจากล่าง ▾]   (มืด / ไฟจากล่าง / แสงจันทร์ / กลางวัน)
ท่าทาง:    นั่งหน้ากองไฟ มองไปทางป่า
```
