# Sketch: แบบจอสองแบบ

ร่างให้ตัดสินรายละเอียดของแบบจอ (D7). เป็นภาพหยาบ ไม่ใช่แบบจริง. ทั้งสองแบบได้วิดีโอ 1080×1920 ตัวหนังสือทุกตัวเป็น Kanit (spoil-maker D21).

## แบบกรอบดำ (แบบ "รุ่นพี่เล่าว่า…")

```text
┌──────────────────────┐
│ ████ พื้นดำ ████████ │
│  ชื่อตอนของ EP        │  ← ตัวขาว ใหญ่ สูงสุด 2 บรรทัด ค้างตลอดคลิป
│  [EP08]              │  ← ป้ายพื้นแดง ตัวขาว
│ ┌──────────────────┐ │
│ │                  │ │  ← ภาพการ์ด 16:9 เต็มความกว้าง (1080×608) กลางจอ
│ │ พีค              │ │  ← ป้ายชื่อตัวละคร มุมล่างซ้ายของภาพ (D19)
│ └──────────────────┘ │
│   «ซับท่อนสั้น»       │  ← ใต้ภาพ ตัวขาวใหญ่ ทีละท่อน (spoil-maker D20)
│ ████████████████████ │
│      ชื่อช่อง         │  ← ตัวเทา เล็ก ค้างตลอดคลิป
└──────────────────────┘
```

## แบบเต็มจอ (แบบคลิปตลก)

```text
┌──────────────────────┐
│ ┌ พีค / สายแฟ ┐      │  ← ป้ายชื่อตัวละคร มุมบนซ้าย (D19)
│                      │
│                      │
│     ภาพการ์ด 9:16     │  ← เต็มจอ 1080×1920
│                      │
│   «ซับท่อนสั้น»       │  ← ตัวขาว ขอบดำหนา ราว 60% ของความสูง
│                      │
│                      │
└──────────────────────┘
```

ไม่มีชื่อตอน ป้าย EP หรือชื่อช่อง (D7).

## ส่วนที่ต้องตัดสิน

| ส่วน | กรอบดำ | เต็มจอ |
|---|---|---|
| ชื่อตอนและป้าย EP | บนสุด ค้างตลอด | — |
| ซับ | ใต้ภาพ | ทับภาพ ราว 60% ของความสูง |
| สีเน้นคำในซับ | ไม่มี | ไม่มีในรอบแรก (เสนอ) |
| ป้ายชื่อตัวละคร | มุมล่างซ้ายของภาพ | มุมบนซ้าย |
| ข้อความป้ายชื่อ | ชื่อ หรือ "ชื่อ / คำสั้น" | เหมือนกัน |
| ป้ายชื่อขึ้นนาน | ตลอดการ์ดแรกที่ตัวละครออก | เหมือนกัน |
| ชื่อช่อง | ล่างสุด ค้างตลอด | — |
