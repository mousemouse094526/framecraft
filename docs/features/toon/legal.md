# Legal check: toon

**Jurisdiction:** Thailand — checked 2026-11-09

- คลิปใช้แบบไม่หารายได้ (ADR-0007, ADR-0017)
- ผู้ใช้เป็นคนเผยแพร่คลิปเอง แอปจบที่ไฟล์ mp4 (D2)
- เสียงเล่า OmniVoice โดยไม่มีเครดิตตรวจแล้วใน [spoil-maker legal.md](../spoil-maker/legal.md) ข้อ 2; Qwen3.5, pythainlp, Kanit ในข้อ 4 — toon ใช้ตัวเดิม ไม่ตรวจซ้ำ

## 1. ใช้ FLUX.2 klein 4B (ไฟล์ GGUF ของ unsloth และ text encoder Qwen3-4B) สร้างภาพในคลิปที่เผยแพร่ (D6, D34, D49)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- คง license Apache-2.0 ของทั้งสาม repo ไว้ใน `NOTICE.md` และหน้า Setup status [1][2][3]
- ไม่ใช้สร้างเนื้อหาที่ model card ห้าม: ผิดกฎหมาย หลอกลวง เกี่ยวกับผู้เยาว์ในทางเพศ คุกคาม หรือภาพลับไม่ยินยอม [1]

ใช้ได้กับทุกไฟล์ GGUF ใน repo เดียวกัน (Q8_0, Q6_K, Q4_K_M ของ D49): license ระดับ repo เป็น Apache-2.0 [2]

## 2. เอาไฟล์ภาพของผู้ใช้เข้าเป็นภาพอ้างอิงตัวละคร แล้วเผยแพร่คลิปที่มีตัวละครนั้น (D31)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- ภาพหรือตัวละครเป็นงานของผู้ใช้เอง หรือได้รับอนุญาตจากเจ้าของ: วาดตามลักษณะสำคัญของตัวละครที่มีเจ้าของคือการดัดแปลง ซึ่งเป็นสิทธิของเจ้าของแต่ผู้เดียว [4]
- ไม่ใช้ภาพของคนจริงที่ระบุตัวได้ในเรื่องที่ทำให้เสียชื่อเสียง ถูกดูหมิ่น เกลียดชัง หรืออับอาย; การนำภาพคนอื่นที่ดัดแปลงด้วยวิธีอิเล็กทรอนิกส์เข้าระบบที่คนทั่วไปเข้าถึงได้แบบนั้นมีโทษจำคุกไม่เกิน 3 ปี หรือปรับไม่เกิน 200,000 บาท [5]
- หน้าเอาไฟล์เข้าบอกผู้ใช้สองข้อนี้ก่อนเลือกไฟล์

## 3. สร้างตัวละครด้วย AI จากคำอธิบาย แล้วเผยแพร่ (D31)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- คำอธิบายไม่สั่งให้วาดตัวละครที่มีเจ้าของ หรือคนจริงที่ระบุตัวได้ ในแบบที่ข้อ 2 ห้าม [4][5]

## 4. เอาไฟล์เสียงหรือเสียงจากลิงก์เข้าคลังเสียงพื้น แล้วใช้ในคลิปที่เผยแพร่ (D5, D39)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- เสียงเป็นของผู้ใช้เอง หรือ license อนุญาตให้ใช้ซ้ำในวิดีโอที่เผยแพร่ (เช่น CC0 หรือเสียงปลอดค่าลิขสิทธิ์ตามเงื่อนไขของผู้ให้): สิ่งบันทึกเสียงของคนอื่นที่นำออกเผยแพร่โดยไม่ได้รับอนุญาตเป็นการละเมิด [4]
- ลิงก์ที่โหลดมาจากเว็บที่ยอมให้โหลด หรือผู้ใช้ได้รับอนุญาต: ToS ของ YouTube ห้ามดาวน์โหลดเนื้อหา (spoil legal.md ข้อ 1, 7)
- ทำตามเงื่อนไขเครดิตของ license นั้นเอง (เช่น CC BY) ในคำอธิบายคลิป

## 5. เผยแพร่คลิปที่ภาพทั้งหมดสร้างด้วย AI โดยไม่ติดป้ายว่าเป็น AI (D2, D6)

**Verdict: ALLOWED** [6][7]

ยังไม่มีกฎหมายไทยที่บังคับติดป้าย: ร่าง พ.ร.บ. ว่าด้วยปัญญาประดิษฐ์ ยังเป็นร่างรับฟังความเห็นเดือนกรกฎาคม 2569 และหัวข้อที่ร่างให้แจ้ง (ความมั่นคง เลือกตั้ง การลงทุน อาหารและยา การปลอมตัว) ไม่รวมการ์ตูนเล่าเรื่อง [6]. YouTube ไม่บังคับแจ้งสำหรับภาพเคลื่อนไหวที่ไม่สมจริง [7]. UNVERIFIED — from model knowledge, verify before relying: สถานะของร่างเช็คจากบทความของสำนักกฎหมายและข่าว ไม่ได้เช็คในราชกิจจานุเบกษาหรือเว็บ ETDA โดยตรง.
