## Destination

- คลิปตัวอย่างที่สอง (แบบเต็มจอ): https://www.youtube.com/shorts/jmZjT6PvdWM — ตลก โทนสว่าง ภาพ 9:16 เต็มจอ, ซับขาวขอบเงาทับกลางภาพ (บางคำสีแดง), ป้ายชื่อตัวละคร ("พีค / สายแฟ") และข้อความไทยในภาพ (ป้ายราคา, แจ้งเตือนมือถือ).

- ผลค้นโมเดลภาพ: [research-image-model.md](../../features/toon/research-image-model.md). ผลค้นโมเดลเสียง (สำหรับรอบสองของ D5): [research-audio-model.md](../../features/toon/research-audio-model.md) — ตัวเลือกแรก Stable Audio 3 small-sfx/small-music (mirror ไม่ gated, Stability Community License, pin torch 2.7.1 ชนกับ 2.8.0).

## Decided

- **ชื่อ tab** — "การ์ตูนเล่า", slug `toon` → D1
- **รอบแรกทำแค่ไหน** — ครบทางแต่บาง ได้ mp4 จริง → D2
- **เก็บตัวละครข้าม EP** — จัดเป็น Series ที่มีชื่อช่อง สไตล์ ตัวละคร ฉากหลัง → D3
- **การขยับภาพ** — นิ่ง/ซูม/เลื่อนต่อการ์ด + ไฟกะพริบทั้งภาพ + จางระหว่างการ์ด ด้วย ffmpeg → D4
- **เสียงบรรยากาศหรือเพลง** — คลังเสียงที่ AI เลือกตามชื่อ; AI สร้างเสียงที่ขาดเป็นรอบสอง → D5
- **โมเดลสร้างภาพ** — FLUX.2 klein 4B พร้อมภาพอ้างอิง → D6
- **แบบจอ** — สองแบบ กรอบดำ หรือเต็มจอ เลือกต่อ Series → D7
- **เสียงเล่าผูกกับอะไร** — Saved voice หลักต่อ Series เปลี่ยนต่อ EP ได้ ไม่มีเสียงต่อตัวละคร → D8
- **คำเรียกสามชั้นของเส้นเรื่อง** — องก์ → ช่วง → การ์ด; ช่วงคือการ์ดติดกันในฉากหลังเดียว เสียงพื้นต่อช่วง → D9
- **องก์ตายตัวหรือแก้ได้** — โครงตั้งต้นที่ Series (แบบหลอน/ตลก) แก้ใน EP ได้ → D10
- **โครงองก์แบบตลกและการแก้โครงของ Series** — ตั้งเรื่อง/ปั่น/พลิก/ตบมุก; แก้โครง Series ได้ มีผลกับ EP ใหม่ → D11
- **ขั้นตอน AI ร่าง** — สองขั้น ไอเดีย → พล็อต (ผู้ใช้แก้) → ช่วงและการ์ด → D12
- **ตัวละครและฉากหลังใหม่จากพล็อต** — เข้า Series ตอนยืนยันพล็อต ยังไม่มีภาพ; สลับเป็นของเดิมได้ → D13
- **ความยาวการ์ดมาจากไหน** — เสียงเล่าจริง + เว้นสั้น ยืดเพิ่มได้; ก่อนมีเสียงประมาณตามความเร็วพูด → D14
- **AI เขียนใหม่ไม่ทับที่ผู้ใช้แก้** — แตกใหม่เฉพาะองก์ที่พล็อตเปลี่ยน, ป้าย "แก้เอง" ระดับการ์ด ยืนยันก่อนทับ → D15
- **ซับทีละวลี** — ใช้ต่อ: ท่อน 2–4 คำ เวลาแบ่งตามจำนวนตัวอักษรของเสียงการ์ด ไม่ใช้ Whisper → spoil-maker D20
- **คลังเสียงอยู่ระดับไหน** — คลังกลางทั้ง tab → D16; รอยต่อช่วง เล่นต่อหรือผสม 1 วินาที วนซ้ำ → D17
- **ดูตัวอย่างก่อน render** — ไม่มีในรอบแรก render จริงเลย → D18
- **ป้ายและข้อความไทยบนภาพ** — ป้ายชื่อตัวละครตอนออกครั้งแรก เปิดปิดต่อ Series; ไม่มีกล่องข้อความอื่น → D19
- **ช่องในการ์ดที่ AI เติมกับที่ผู้ใช้เลือก** — คำบรรยายภาพข้อความอิสระช่องเดียว → D20; ช่องตาม [card-sketch.md](../../features/toon/card-sketch.md) เว้นท้าย 0.3 วิ → D21
- **รายละเอียดแบบจอทั้งสอง** — ตำแหน่งตาม [layout-sketch.md](../../features/toon/layout-sketch.md), Kanit (spoil-maker D21), ไม่มีสีเน้นคำ → D22; ป้าย "ชื่อ / คำสั้น" ตลอดการ์ดแรก → D23
- **ชื่อตอนของ EP** — AI เสนอในพล็อต ผู้ใช้แก้ได้ → D24
- **ลบของที่มีที่ใช้อยู่** — ตัวละคร ฉากหลัง Saved voice ที่ใช้อยู่ลบไม่ได้ → D25
- **ลบ Series** — ลบทุก EP หลังยืนยัน; Saved voice กับคลังเสียงพื้นคงอยู่ → D26
- **แก้ภาพการ์ดที่เสีย** — สร้างใหม่ทั้งภาพ → D27
- **สไตล์ภาพของ Series** — ข้อความอังกฤษช่องเดียว สไตล์ตั้งต้น "หลอนมืด" / "ตลกสว่าง" ไม่มีภาพตัวอย่างสไตล์ → D28
- **ฉากหลังทำงานยังไงในภาพการ์ด** — ส่งเป็นภาพอ้างอิงคู่ตัวละคร โมเดลวาดรวม → D29
- **ตัวละครสูงสุดต่อการ์ด** — 2 ตัว (ภาพอ้างอิงสูงสุด 3) → D30
- **ภาพอ้างอิงตัวละคร** — ภาพเดียวเต็มตัวหน้าตรง สร้าง 3 แบบให้เลือกหรือเอาไฟล์เข้า → D31; เปลี่ยนได้เสมอ ภาพการ์ดเดิมได้ป้าย → D32
- **หลายภาพให้เลือก** — การ์ดละ 1 ภาพ + สร้างที่ขาดทั้งหมดเป็นงานเดียว เก็บภาพก่อนหน้า 1 ภาพ → D33
- **spec ของ klein ต่อ OS** — Mac GGUF Q8_0 แยกขั้น → D34; Windows ไฟล์เดียวกันบน cuda เช็คใน windows-check → D35
- **คำสั่งภาพ** — Qwen แปลคำบรรยายภาพเป็นอังกฤษตอนเริ่มงาน แอปต่อแม่แบบ ห้ามตัวหนังสือ → D36
