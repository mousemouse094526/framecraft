# Map: toon

## Destination

spec `ready-to-build` ของ tab การ์ตูนเล่า รอบแรก (D2): ตั้ง Series กับ EP → AI เขียนบท → การ์ดเส้นเรื่องที่แก้ได้ → ภาพทีละการ์ด → เสียงเล่า → ซับ → เสียงพื้นจากคลังเสียง → render mp4 1080×1920 ตามแบบจอคลิปตัวอย่าง.

## Notes

- คำขอเต็มของผู้ใช้อยู่ในบทสนทนาแรก; สรุป: คลิปตัวอย่าง https://www.youtube.com/watch?v=C2Ffei1ozAo (ช่อง "รุ่นพี่เล่าว่า…" EP08, 92 วินาที) จอดำ, ชื่อเรื่องกับป้าย EP สีแดงบนสุด, ภาพแนวนอนราว 1/3 ความสูงกลางจอ, ซับตัวใหญ่ขึ้นทีละวลีใต้ภาพ, ชื่อช่องล่างสุด; การ์ตูน 2D แบน หัวกลม ตาจุด โทนมืด สีสดแค่แสงไฟ; หนึ่งประโยคต่อหนึ่งภาพ 3–5 วินาที; เสียงเล่าเรียบช้าแบบ "ฉัน".
- คลิปตัวอย่างที่สอง (แบบเต็มจอ): https://www.youtube.com/shorts/jmZjT6PvdWM — ตลก โทนสว่าง ภาพ 9:16 เต็มจอ, ซับขาวขอบเงาทับกลางภาพ (บางคำสีแดง), ป้ายชื่อตัวละคร ("พีค / สายแฟ") และข้อความไทยในภาพ (ป้ายราคา, แจ้งเตือนมือถือ).
- ห้ามใช้คำ "Story" หรือ "เรื่อง" เป็นชื่อสิ่งใน tab นี้ — เป็นของ story-kb (ADR-0023).
- ใช้ต่อโดยไม่ถาม: Qwen3.5 9B และตัวรันต่อ OS (spoil-maker D13, windows-launch D3), Saved voice กับ OmniVoice (spoil-maker D32–D37, ADR-0019), งาน GPU ใน process ลูกทีละงาน (ADR-0012, ADR-0015), ทุกงาน GPU gate แถว `device` (ADR-0026), Mac ก่อน Windows (ADR-0016), ไม่หารายได้ ไม่บังคับเครดิต (ADR-0017), ออกแบบหน้าจอใน Figma หลัง plan (setup-status D9), ffmpeg จาก imageio (ADR-0005), โหลดลิงก์ด้วยตัวโหลดเฉพาะเว็บ (ADR-0029), อัปโหลดไฟล์แบบ body ดิบ (ADR-0028), Qwen บน Windows ต้อง RTX 30xx (windows-launch D10).
- ผลค้นโมเดลภาพ: [research-image-model.md](../../features/toon/research-image-model.md). ผลค้นโมเดลเสียง (สำหรับรอบสองของ D5): [research-audio-model.md](../../features/toon/research-audio-model.md) — ตัวเลือกแรก Stable Audio 3 small-sfx/small-music (mirror ไม่ gated, Stability Community License, pin torch 2.7.1 ชนกับ 2.8.0).
- klein ใช้งานจริงต้องผ่านทาง setup ตาม ADR ที่มีอยู่ ไม่ถาม: ลงทะเบียนและ pin ใน `backend.models` (ADR-0004), Setup script โหลดโมเดลและติดตั้ง `diffusers` ที่ยังไม่มีใน `pyproject.toml` (ADR-0008), มีแถว Status check ของตัวเองที่แสดงใน tab ตั้งค่า (ADR-0009), tab การ์ตูนเล่า gate ด้วยแถว klein กับแถว `device` (ADR-0026). โมเดลที่โหลดตอนลองจริงเป็นของชั่วคราว ไม่ใช่ทางนี้.
- Mac ของผู้ใช้ 16 GB: klein 4B พอดีแบบเฉียด (text encoder ต้องรันก่อนแล้วปล่อย); ราว 1–2 นาทีต่อภาพ (ประมาณ).

## Decided

- **ชื่อ tab** — "การ์ตูนเล่า", slug `toon` → D1
- **รอบแรกทำแค่ไหน** — ครบทางแต่บาง ได้ mp4 จริง → D2
- **เก็บตัวละครข้าม EP** — จัดเป็น Series ที่มีชื่อช่อง สไตล์ ตัวละคร ฉากหลัง → D3
- **การขยับภาพ** — นิ่ง/ซูม/เลื่อนต่อการ์ด + ไฟกะพริบทั้งภาพ + จางระหว่างการ์ด ด้วย ffmpeg → D4
- **เสียงบรรยากาศหรือเพลง** — คลังเสียงที่ AI เลือกตามชื่อ; AI สร้างเสียงที่ขาดเป็นรอบสอง → D5
- **โมเดลสร้างภาพ** — FLUX.2 klein 4B พร้อมภาพอ้างอิง → D6
- **แบบจอ** — สองแบบ กรอบดำ หรือเต็มจอ เลือกต่อ Series → D7
- **เสียงเล่าผูกกับอะไร** — Saved voice หลักต่อ Series เปลี่ยนต่อ EP ได้ ไม่มีเสียงต่อตัวละคร → D8
- **คำเรียกสามชั้นของเส้นเรื่อง** — องก์ → ช่วง → การ์ด; ช่วงคือการ์ดติดกันในฉากหลังเดียว เสียงพื้นต่อช่วง → D9
- **องก์ตายตัวหรือแก้ได้** — โครงตั้งต้นที่ Series (แบบหลอน/ตลก) แก้ใน EP ได้ → D10
- **โครงองก์แบบตลกและการแก้โครงของ Series** — ตั้งเรื่อง/ปั่น/พลิก/ตบมุก; แก้โครง Series ได้ มีผลกับ EP ใหม่ → D11
- **ขั้นตอน AI ร่าง** — สองขั้น ไอเดีย → พล็อต (ผู้ใช้แก้) → ช่วงและการ์ด → D12
- **ตัวละครและฉากหลังใหม่จากพล็อต** — เข้า Series ตอนยืนยันพล็อต ยังไม่มีภาพ; สลับเป็นของเดิมได้ → D13
- **ความยาวการ์ดมาจากไหน** — เสียงเล่าจริง + เว้นสั้น ยืดเพิ่มได้; ก่อนมีเสียงประมาณตามความเร็วพูด → D14
- **AI เขียนใหม่ไม่ทับที่ผู้ใช้แก้** — แตกใหม่เฉพาะองก์ที่พล็อตเปลี่ยน, ป้าย "แก้เอง" ระดับการ์ด ยืนยันก่อนทับ → D15
- **ซับทีละวลี** — ใช้ต่อ: ท่อน 2–4 คำ เวลาแบ่งตามจำนวนตัวอักษรของเสียงการ์ด ไม่ใช้ Whisper → spoil-maker D20
- **คลังเสียงอยู่ระดับไหน** — คลังกลางทั้ง tab → D16; รอยต่อช่วง เล่นต่อหรือผสม 1 วินาที วนซ้ำ → D17
- **ดูตัวอย่างก่อน render** — ไม่มีในรอบแรก render จริงเลย → D18
- **ป้ายและข้อความไทยบนภาพ** — ป้ายชื่อตัวละครตอนออกครั้งแรก เปิดปิดต่อ Series; ไม่มีกล่องข้อความอื่น → D19
- **ช่องในการ์ดที่ AI เติมกับที่ผู้ใช้เลือก** — คำบรรยายภาพข้อความอิสระช่องเดียว → D20; ช่องตาม [card-sketch.md](../../features/toon/card-sketch.md) เว้นท้าย 0.3 วิ → D21
- **รายละเอียดแบบจอทั้งสอง** — ตำแหน่งตาม [layout-sketch.md](../../features/toon/layout-sketch.md), Kanit (spoil-maker D21), ไม่มีสีเน้นคำ → D22; ป้าย "ชื่อ / คำสั้น" ตลอดการ์ดแรก → D23
- **ชื่อตอนของ EP** — AI เสนอในพล็อต ผู้ใช้แก้ได้ → D24
- **ลบของที่มีที่ใช้อยู่** — ตัวละคร ฉากหลัง Saved voice ที่ใช้อยู่ลบไม่ได้ → D25
- **ลบ Series** — ลบทุก EP หลังยืนยัน; Saved voice กับคลังเสียงพื้นคงอยู่ → D26
- **แก้ภาพการ์ดที่เสีย** — สร้างใหม่ทั้งภาพ → D27

## Open

1. **ลอง klein บน Mac** — memory สูงสุดและเวลาต่อภาพกับภาพอ้างอิง 0–3 ภาพ, ตัวละครเหมือนเดิมใน 10 ภาพไหม, สองตัวในภาพเดียวปนหน้ากันไหม, โทนมืดสีสดแค่ไฟได้จากคำสั่งไหม, ใช้ GGUF บน MPS ได้ไหม · kind: task
3. **สไตล์ภาพของ Series** — ข้อความสไตล์อย่างเดียว, หรือมีภาพตัวอย่างสไตล์เป็นภาพอ้างอิงด้วย; มีสไตล์ตั้งต้นแบบคลิปตัวอย่างไหม · kind: interview · blocked by: ลอง klein บน Mac
4. **ภาพอ้างอิงตัวละคร** — แผ่นเดียวรวมหน้าตรง เฉียง และ 3–5 สีหน้า หรือแยกภาพ; สร้างจากข้อความอย่างเดียวหรือผู้ใช้เอาภาพเข้าได้; ล็อกแล้วแก้ได้ไหมเมื่อมี EP ใช้อยู่ · kind: interview · blocked by: ลอง klein บน Mac
5. **ฉากหลังทำงานยังไงในภาพการ์ด** — ส่งภาพฉากหลังเป็นภาพอ้างอิงคู่ตัวละคร (แสงตกถูก แต่ฉากเพี้ยนได้) หรือวางตัวละครทับฉากหลัง · kind: interview · blocked by: ลอง klein บน Mac
12. **หลายภาพให้เลือก** — กี่แบบต่อการ์ด; สร้างทั้ง EP เป็นงานเดียว (30–60 นาที) หรือทีละการ์ด; ภาพที่ไม่เลือกเก็บไหม · kind: interview · blocked by: ลอง klein บน Mac
18. **ตัวละครสูงสุดต่อการ์ด** — กี่ตัวในภาพเดียว (D21) ตามผลว่าสองตัวปนหน้ากันไหม · kind: interview · blocked by: ลอง klein บน Mac

## Fog

- spec ของ klein ต่อ OS (ADR-0025) และการ์ดขั้นต่ำบน Windows — ขึ้นกับผลลองจริงและ bf16 บน RTX 20xx
- คำสั่งภาพ: แปลงท่าทาง แสง ฉากหลัง ตัวละครเป็นข้อความถึงโมเดลยังไง ให้ภาพคงสไตล์ และไม่วาดตัวหนังสือในภาพ (D19)

## Out of scope

- AI สร้างเสียงที่ขาดในคลังเสียง — รอบสองตาม D5
- โมเดลทำภาพเคลื่อนไหว — ไม่เลือกตาม D4
- ฝึก LoRA ต่อตัวละคร — ไม่เลือกตาม D6
- ตัวเล่นตัวอย่างทั้ง EP หรือ render ร่าง — ไม่มีในรอบแรกตาม D18
- กล่องข้อความบนภาพนอกจากป้ายชื่อ (ป้ายราคา แจ้งเตือน) — ไม่มีในรอบแรกตาม D19
- สีเน้นคำในซับ — ไม่มีในรอบแรกตาม D22
- แก้ภาพการ์ดเฉพาะจุด — ไม่มีในรอบแรกตาม D27
