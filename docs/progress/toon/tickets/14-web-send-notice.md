# 14: ส่งแล้วเช็คคำตอบทางเดียวในหน้าเว็บ toon

**What to build:** ทุก hook ของหน้าเว็บ toon ที่ส่งค่าไป backend อ่านคำตอบผ่านตัวช่วยเดียว (status ที่ถือว่าสำเร็จ, คำเตือน, การปฏิเสธที่มี code ให้เช็ค) และเก็บข้อความถึงผู้ใช้เป็น `Notice` แบบเดียวกัน. ผู้ใช้เห็นข้อความและพฤติกรรมเหมือนเดิมทุกหน้า.

**Blocked by:** None (can start immediately)

**Covers:**
- Decisions: D65, D68
- Blocked: #29 (feature review รอบห้า)

**Status:** done

## Acceptance criteria

- `sendEdit` รับ status ที่ถือว่าสำเร็จ (ไม่ใช่แค่ 200/201), ส่งคำเตือนกลับ และคืนการปฏิเสธพร้อม code ให้ผู้เรียกเช็ค; มี test ของตัวเอง
- คลังเสียงพื้น เปลี่ยนชื่อ ลบ (รวม `in_use`) และ import → ข้อความเดิม ผ่าน `sendEdit`
- render เริ่มและลบ, เริ่มงานของ EP, รายการ EP, ตัวละครและฉากหลัง, ส่งภาพอ้างอิงที่เลือก, ฟอร์ม Series, รายการ Series → ข้อความเดิม ผ่าน `sendEdit`; ไม่มี hook ของ toon ที่เช็ค status แล้วสร้างข้อความเอง
- hook ภาพอ้างอิง ฟอร์ม Series และรายการ Series เก็บ `Notice` แทนข้อความล้วน; จอแสดงเหมือนเดิม
- test ของ hook และหน้าที่มีอยู่ยังผ่าน จำนวนไม่ลด
- typecheck, test, build ของหน้าเว็บ และ `uv run pytest` เขียว
