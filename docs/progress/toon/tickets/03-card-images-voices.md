# 03: ภาพการ์ดและเสียงเล่า

**What to build:** ผู้ใช้สร้างภาพการ์ดทีละใบ หรือกด "สร้างภาพที่ขาดทั้งหมด" แล้วทิ้งไว้ข้ามคืน หยุดได้ และเห็นภาพขึ้นทีละใบ. สลับกลับภาพก่อนหน้าได้ เห็นการ์ดที่ภาพอ้างอิงเปลี่ยนและสร้างใหม่ทั้งหมดในงานเดียว. สร้างและฟังเสียงเล่าทีละการ์ดด้วย Saved voice ของ EP.

**Blocked by:** 02: EP, พล็อต และเส้นเรื่อง

**Covers:**
- Decisions: D8 (`stale_audio`), D13 (การ์ด `no_ref` ถูกข้าม), D14, D21 (ปุ่มเสียง), D27, D29, D30, D32 (`stale_ref`), D33, D34, D36, D37, D44, spoil-maker D32–D37
- ADR: 0010, 0012, 0015, 0019, 0026, 0031, 0034
- Screens: เส้นเรื่อง (การ์ด) ส่วนภาพการ์ด ปุ่มเสียง ป้าย "ภาพอ้างอิงเปลี่ยน" และ "ยังไม่มีภาพอ้างอิง" ปุ่มสร้างภาพที่ขาดทั้งหมด ปุ่มสร้างภาพใหม่การ์ดที่ภาพอ้างอิงเปลี่ยน รายการภาพอ้างอิงที่ต้องสร้างก่อน
- Seams: 1 (Image job, `failed_cards`, ภาพก่อนหน้า, start ใหม่, `stale_ref`, Voice job, `stale_audio`), 3 (ภาพขึ้นระหว่างงาน)
- User stories: 3 (ป้ายการ์ดที่ใช้หน้าเก่า), 8, 9

**Status:** done

## Acceptance criteria

### ย้ายก่อน

- ลูปสร้างเสียงทีละข้อความของ `SentenceVoicer` ย้ายเป็นฟังก์ชันกลางที่รับ (ข้อความ, clone prompt, speed) คืน wav ทีละอัน → test ของ spoil-maker ผ่านเหมือนเดิม

### Image job

- Image job `scope: missing` ด้วย klein ปลอม → การ์ด `no_image` ได้ภาพตามลำดับ; การ์ด `no_ref` นับใน `skipped` และอยู่ใน `missing_refs`
- ทุกการ์ดเป็น `no_ref` → `400` `nothing_to_draw` พร้อม `missing_refs`; Image job การ์ดเดียวที่ `no_ref` → `400` `no_ref`
- ยกเลิกกลางงาน → ภาพที่เสร็จแล้วอยู่ ภาพที่กำลังสร้างถูกทิ้ง
- klein ปลอมล้มหนึ่งการ์ด → การ์ดนั้นอยู่ใน `failed_cards` งานไปต่อจน `done`
- สร้างภาพใหม่ → `previous_image` เป็นภาพเดิม; สร้างอีกครั้ง → ไฟล์ภาพก่อนหน้าเดิมหายจากดิสก์; `swap-image` สลับสองภาพ
- PNG ใน `images/` ที่ `ep.json` ไม่อ้าง และ `.image-job/` → หายหลัง start ใหม่
- start app ใหม่ (`paths.ROOT` เดิม) แล้วเริ่ม `scope: missing` → สร้างเฉพาะการ์ดที่ยังไม่มีภาพ
- เปลี่ยนภาพอ้างอิงตัวละคร หรือเปลี่ยนตัวละครของการ์ด → การ์ด `stale_ref`; `scope: missing` ไม่สร้างมัน; `scope: stale_ref` สร้างใหม่
- การ์ดถูกลบระหว่างงาน → ภาพของมันถูกทิ้ง
- คำสั่งภาพตามแม่แบบใน spec › คำสั่งภาพ; `FakeLlm` ตอบ `scene` ว่าง → ใช้ค่าสำรองของ spec; คำสั่งภาพไม่อยู่ใน response ของ `GET` EP
- ภาพการ์ด 1024×576 ใน Series `frame`, 576×1024 ใน `full`
- ดิสก์ว่างน้อยกว่า 1 GiB → `507` `disk_full`

### Voice job

- Voice job ด้วย `FakeTts` → การ์ดมี `audio` และ `GET …/cards/{kid}/audio` ได้ wav; การ์ดเงียบ → `400`
- `PATCH` EP `voice_id` → การ์ดที่มีเสียงเป็น `stale_audio`; แก้ `text` → `stale_audio`
- แถว `model_omnivoice` `missing` → `503` `not_ready`
- `gpu.Kind` มี `toon_voice` ใน `RUNNING_NAMES` ("สร้างเสียงเล่า"); Voice job ระหว่าง Describe job → `409` `gpu_busy`

### หน้าเว็บ

- ระหว่าง Image job `done` เพิ่มจาก 1 เป็น 2 → ภาพของการ์ดที่สองขึ้นโดยไม่ reload (e2e)
- "สร้างภาพที่ขาดทั้งหมด" ที่มีการ์ดถูกข้าม → เห็นจำนวนที่ข้ามและรายการตัวละครกับฉากหลังที่ต้องสร้างภาพอ้างอิงก่อน พร้อมลิงก์ (e2e)
- หน้าตาตรงแบบของจอเส้นเรื่อง (Source ยัง `pending`: Blocked #7)

### เช็คมือบน Mac M1 16 GB

- Image job `scope: missing` ราว 20 การ์ด กรณี 3 ภาพอ้างอิง → peak ทั้งระบบไม่เกิน ~12 GB ไม่ swap; จดเวลาต่อภาพใน `progress.md`
- ตัวละครหนึ่งตัวในราว 5 การ์ดของ EP แรกและ EP ที่สอง → ดูด้วยตาว่าหน้าเหมือนภาพอ้างอิง จดผลใน `progress.md`
- ปิด backend ระหว่าง "สร้างภาพที่ขาดทั้งหมด" แล้วเปิดใหม่ → ภาพที่เสร็จก่อนปิดยังอยู่ กดใหม่สร้างเฉพาะที่เหลือ
