# 07: ส่วนตัดช่วงใน tab คลิป

**What to build:** เลือกคลิปใน tab คลิปแล้วกด "ตัดช่วง" เห็น timeline ใต้ player ลากหรือพิมพ์เวลาช่วง A–B และ C–D ได้ เห็นความยาวที่จะเหลือ แล้วกด "ตัดคลิป". คลิปที่มีข้อมูลอยู่แล้วเห็นคำยืนยันว่าจะลบอะไร; ระหว่างตัดเห็น % และยกเลิกได้; จบแล้ว player เล่นไฟล์ใหม่และแถวมีป้าย "ตัดแล้ว".

**Blocked by:** 06: Backend Trim job และ API; แบบ Figma ของ "ส่วนตัดช่วง" (Blocked row ใน progress.md)

**Covers:**
- Decisions: D37, D38, D40, D41
- Screens: ส่วนตัดช่วง
- Seams: 4 (ข้อของส่วนตัดช่วง)
- User stories: 12, 13

**Status:** done

## Acceptance criteria

- test ของ seam 4 ทุกข้อของส่วนตัดช่วงผ่าน; test เดิมของ tab คลิปผ่านหมด
- ทุก state ในตาราง spec › Frontend › ส่วนตัดช่วง และทุกกฎของส่วนตัดช่วงทำตาม spec
- `src` ของ player ทุกที่มี `?v=` ตาม D41 และเปลี่ยนหลังตัด
- หัวลากของ timeline ใช้แป้นพิมพ์ได้ตาม spec และแตะได้บน 375px
- เช็คมือบน Mac ผ่าน Vite proxy: ตัดโฆษณาต้นหนังและตอนจบที่ถอดไว้แล้ว → เห็นคำยืนยัน, % เดินจนจบ, player เริ่มที่ฉากแรกของเรื่อง, แถวมี "ตัดแล้ว" และไม่มี "ถอดแล้ว" (e2e)
- กดยกเลิกระหว่างตัด → "ยกเลิกแล้ว", ช่วงยังอยู่, player เล่นไฟล์เดิมได้ (e2e)
- หน้าตาตรงแบบ Figma ของ "ส่วนตัดช่วง" ทั้ง desktop และ 375px
