# 05: หน้าสองคอลัมน์และกล่องถอดบทพูด

**What to build:** tab สปอยเป็นสองคอลัมน์: รายการคลิปซ้าย ลูกศร → กลาง กล่องถอดบทพูดขวา (375px เรียงบนลงล่าง ลูกศร ↓). กดแถว = เลือกคลิปเข้ากล่องพร้อม player; กด "ถอดบทพูด" เห็น % และยกเลิกได้; จบแล้วเห็น Transcript ทีละบรรทัดพร้อมเวลา กดบรรทัดแล้ว player กระโดด, Copy, `.txt`, `.srt`; แถวที่ถอดแล้วมี badge "ถอดแล้ว" และกล่องมี alert "คลิปนี้ถอดแล้ว".

**Blocked by:** 04: Backend งานถอดบทพูดและ API (done)

**Covers:**
- User stories: 8, 9, 10, 11
- Decisions: D18, D22, D23, D25, D29, D33
- Screens: layout สองคอลัมน์, กล่องถอดบทพูด
- Seams: 4 (ข้อของกล่องถอดบทพูด)

**Status:** done

## Acceptance criteria

- test ของ seam 4 ทุกข้อของกล่องถอดบทพูดผ่าน; test เดิมของ tab สปอยปรับให้ player อยู่ในกล่องแล้วผ่านหมด
- ทุก state ในตาราง spec › Frontend › กล่องถอดบทพูด และผลของ `POST /transcriptions` ทุก code แสดงตาม spec
- เปิด tab ขณะงานถอดยังไม่จบ → คลิปนั้นถูกเลือกและเห็น %; poll ของงานถอดกับงานโหลดเดินแยกกันได้พร้อมกัน
- ลบคลิปที่เลือกอยู่ → กล่องกลับเป็น "เลือกคลิปจากรายการ"; ลบคลิปที่กำลังถอด → ข้อความ `transcribing` ใต้แถว
- เช็คมือบน Mac ผ่าน Vite proxy: เลือกหนังที่ถอดไว้ใน 04 → เห็น Transcript, กดบรรทัดแล้ว player ไปเวลานั้น, Copy แล้ววางได้ข้อความครบ, โหลด `.txt` และ `.srt` ได้; ถอด Shorts ใหม่ตั้งแต่กดจนเห็นบรรทัด
- หน้าตาตรง Figma frame 14–19 และ component `Transcript panel`, `Transcript line`, `Player` ทั้ง desktop และ 375px
