# 02: แถบนำทางแบบกลุ่มและเมนูจอแคบ

**What to build:** บนจอตั้งแต่ 640px แถบ tab มีเส้นคั่นสามกลุ่ม ติดตั้ง | คลิป · คลังความรู้ · คลังเสียง | สปอย · การ์ตูนเล่า. จอแคบกว่า 640px แถบเป็นปุ่มเดียวชื่อหน้าที่เปิด กดแล้วเปิดรายการตามกลุ่ม "เตรียมของ" และ "ทำคลิป" จึงไม่มี scroll แนวนอนที่ 375px.

**Blocked by:** 01: คลังเสียงกลางที่ tab คลังเสียง

**Covers:**
- Decisions: D3, spoil-maker D53
- Screens: แถบนำทาง
- Seams: 3 (ปุ่มเมนู)
- User stories: 2

**Status:** in-progress

## Acceptance criteria

- `TABS` → แต่ละ tab มีกลุ่ม: `setup` ไม่มี, `prep` (คลิป คลังความรู้ คลังเสียง), `make` (สปอย การ์ตูนเล่า)
- จอกว้าง → แต่ละกลุ่มมี `aria-label` ชื่อกลุ่ม ไม่มีข้อความหัวกลุ่ม; tab ที่เปิดอยู่เด่นกว่า
- กดปุ่มเมนู → `aria-expanded` `true` เห็นติดตั้งบนสุด แล้วหัว "เตรียมของ" และ "ทำคลิป" (e2e)
- เลือกรายการในเมนู → เปิด tab นั้นและเมนูปิด (e2e)
- `Esc` → เมนูปิดและ focus กลับที่ปุ่ม; คลิกนอก → เมนูปิด (e2e)
- ปุ่มเมนู → แสดงชื่อหน้าที่เปิดอยู่พร้อมไอคอนเมนู
- หน้าตาตรงแบบของจอแถบนำทาง (Blocked #1)

### เช็คมือบนแอปจริง

- 375px → ไม่มี scroll แนวนอนและเห็นปุ่มเมนู; 640px และ 1440px → แถบ tab แบบกลุ่ม; จดผลใน `progress.md`
