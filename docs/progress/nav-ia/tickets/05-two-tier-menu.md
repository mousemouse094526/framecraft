# 05: เมนู 2 ชั้น

**What to build:** เมนูหลักมีแค่หัวหมวดกับลิงก์ตาม spec › Design › ชั้นของเมนู: ไม่มีหัวกลุ่มของหัวข้อ ไม่มี "สร้างชุดใหม่" "ชุดทั้งหมด" "เพลงทั้งหมด" "reel ทั้งหมด"; การ์ตูนเล่า reel cover reel กลอง เป็นลิงก์ prefix; ล่าสุดเป็นหมวดของตัวเองระหว่างดนตรีกับคลัง; หัวหน้าเป็นชื่อลิงก์ที่เปิด หรือชื่อลิงก์แหล่งในหน้าที่ลึกกว่า.

## Acceptance criteria

- ไม่มีล่าสุด → กลุ่มในเมนูคือ เล่าเรื่อง · ดนตรี · คลัง · ตั้งค่า ไม่มีกลุ่มซ้อน; ลิงก์ตามลำดับ ทำสปอย · คลิปทั้งหมด · การ์ตูนเล่า · reel cover · reel กลอง · คลังความรู้ · คลังเสียง · เสียงพากย์ · ติดตั้ง
- มีล่าสุด → หมวด "ล่าสุด" ระหว่างดนตรีกับคลัง เรียง การ์ตูนเล่า → reel cover → reel กลอง ไม่ว่าที่เก็บเรียงอย่างไร แต่ละลิงก์มีบรรทัดรอง (`aria-describedby`) เป็นชื่อแหล่ง
- ทุกแถวของ spec › Design › หัวหน้าและลิงก์ที่เปิด: ลิงก์ `aria-current="page"` และ `<h1>` ตรงตัว; `<h1>` ไม่เปลี่ยนเมื่อหน้ารายละเอียดเพิ่มตัวเองเข้าล่าสุด
- `#/toon/new` → ลิงก์การ์ตูนเล่าเปิด หน้าสร้าง Series ขึ้น; ปุ่ม "สร้าง Series" ที่ `#/toon` ยังพาไป
- `#/toon?x` → หน้าติดตั้ง ลิงก์ติดตั้งเปิด
- ล่าสุดเก่าใต้กุญแจ `songs` → ลิงก์ `#/covers/{id}` ในหมวดล่าสุด บรรทัดรอง "reel cover"
- test เดิมที่ assert `<h1>` "{หัวข้อ} / {รายการ}" หรือ "คลัง / …" และที่กดลิงก์ที่ตัดออก แก้ตาม spec › Testing decisions ไม่ลดสิ่งที่ตรวจ
- ภาพแคปจากของจริงที่ 375px (drawer เปิด, ล่าสุดเต็มสามแหล่ง) และ 1280px แนบใน `progress.md`
- checks ทั้งสี่ผ่าน
