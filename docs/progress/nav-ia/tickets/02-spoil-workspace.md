# 02: สปอยเป็นพื้นที่ทำงานเดียว

**What to build:** `#/spoil` เปิดพื้นที่ทำงานสปอยที่ขั้น เลือกคลิป · ตรวจแก้บท · ผล render เป็นปุ่มในหน้า: เปิดที่ตรวจแก้บทเมื่อมีบทหรือกำลังร่าง และเดินขั้นเองเมื่อร่างเริ่ม ยกเลิกร่าง หรือ render เสร็จ โดยที่อยู่ไม่เปลี่ยน. `#/spoil/review` และ `#/spoil/renders` เก่าพามาที่ `#/spoil`.

**Blocked by:** 01: เมนูและที่อยู่ใหม่ พร้อม redirect

**Covers:**
- Decisions: D5, D9 (step hashes), D10, D14 (ขั้นที่ผู้ใช้เลือกชนะ, เปลี่ยนขั้นอัตโนมัติเฉพาะจากขั้นต้นทาง, ทำสปอยซ้ำ)
- ADR: 0069
- Seams: 2
- User stories: 3

**Status:** ready-for-agent

## Acceptance criteria

- ไม่มี Spoil draft → เลือกคลิปเปิด; มี draft หรือกำลังร่าง → ตรวจแก้บทเปิด; `location.hash` เป็น `#/spoil` ตลอด
- กดขั้นในแถบ → ขั้นนั้นเปิด `aria-current="step"`; กดก่อนโหลดเสร็จ → ขั้นนั้นคงอยู่
- ร่างบทเริ่ม → ตรวจแก้บท; ยกเลิกร่างจากการ์ดร่าง → เลือกคลิป
- render เสร็จขณะตรวจแก้บทเปิด → ผล render; ขณะขั้นอื่นเปิด → ขั้นไม่เปลี่ยน
- "ไปที่ตรวจแก้บท" / "ไปที่ตั้งค่าคลิปสปอย" เปลี่ยนขั้น
- เสียงพื้น → คลังเสียง `?back=#/spoil` และปุ่มกลับพามา `#/spoil`
- `#/spoil/review`, `#/spoil/renders` → `#/spoil`
