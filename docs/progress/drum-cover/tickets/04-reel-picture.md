## Acceptance criteria

### prefactor ของ video-gen

- `background_image` และ `stick_tip` ของ video-gen เป็น public และ helper ของ captions ที่ reel ใช้เปิดออก → test เดิมของ video-gen frames, captions, render ผ่านโดยไม่แก้ assertion; บทเรียนตัวอย่างได้ `text.ass` เดิมทุกตัวอักษร

### ภาพ

- ตารางชิ้นของ sketch: ทุกคู่ไม่ทับกันที่ขนาด 1.2 เท่า อยู่ในกรอบ x 54–1026, y 400–1090; หัวไม้ที่ที่พักไม่อยู่ในชิ้นใด; สีแปดชิ้นต่างกันทุกคู่
- เฟรมที่เวลาของ snare → จุดวัดสีของ `SNARE` เป็นสีเติมเต็มของ snare; เฟรมที่ไม่มีการตีใกล้ ๆ → สีพัก 30 %; `t` เดียวกันสองครั้ง → bytes เดียวกัน
- การตี R ที่ hihat แล้ว L ที่ snare → พิกเซลบนไม้แต่ละข้างเป็นสีของมือนั้น
- การตีมีแค่ hihat_closed, snare, kick → เลน 3 แถว สูง 84 เรียง HI-HAT, SNARE, KICK; หัวโน้ตของ snare ตอนถึงเวลาการตีอยู่ที่ x 330 แถว SNARE
- หางเสียง 1.5 วิ → เลนหยุดนิ่ง; เฟรมสองเฟรมในหางเหมือนกันยกเว้นชิ้นที่ยังเรืองอยู่

### ตัวหนังสือ

- `text.ass` ของ reel มีป้ายชิ้นทุกชิ้นตลอดคลิป ชื่อเลนเฉพาะชิ้นที่มี "ห้อง 1"/"ห้อง 2" เริ่มที่ downbeat ตัว L/R ในหัวโน้ตมือ (ไม่มีของเท้าและ `hand` `null`) และหัวเรื่อง บรรทัดรอง คำบรรยายแบบเดิม (หัวเรื่องบีบไม่เกิน 760 px)
- ห้อง 5 จังหวะ → จังหวะที่ 5 จุดที่ 4 สว่าง

### render

- `POST /render` → mp4 1080×1920 30 fps h264 + aac ยาว `length_s` ± 0.1; เสียงตรงภาพ: sample แรกของคลิก snare กับเฟรมแรกที่จุดวัดสีของ `SNARE` เติมเต็ม ห่าง ≤ 1 เฟรม
- reel 30 วินาทีบน Mac ของเจ้าของ render ≤ 60 วินาที (วัดมือ บันทึกใน progress.md)
- ดึงเฟรม reel Yellow 11.5–30 สามถึงสี่เฟรม (ช่วงที่มีหลายชิ้นพร้อมกัน) เก็บไว้ให้เจ้าของดูและบันทึกใน progress.md; เจ้าของยืนยันว่าอ่านออก = Blocked แถวของเจ้าของ (D27)
