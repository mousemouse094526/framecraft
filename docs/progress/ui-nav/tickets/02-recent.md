# 02: ล่าสุดในเมนู

**What to build:** ชุดหรือ EP บทเรียนกลอง และเพลงที่เปิดล่าสุดในเบราว์เซอร์นี้ ขึ้นใต้หัวข้อของมันในเมนูหลัก ไม่เกิน 3 รายการ กดแล้วกลับไปที่นั้นทันที. ลบชิ้นใดในแอปแล้วมันหายจากล่าสุดด้วย.

**Blocked by:** 01: เมนูหลัก 5 หัวข้อ พร้อมขั้นและคลัง

**Covers:**
- Decisions: D5, D10 (ชื่อ 80 ตัวอักษร, hash ตรงรูป route, อ่านก่อนเขียน), D11 (หน้าที่เขียนและลบล่าสุด)
- Seams: 2
- User stories: 3

**Status:** ready-for-agent

## Acceptance criteria

- `EpListPage`, `EpPage`, `LessonEditor`, `SongPage` โหลดสำเร็จ → `framecraft.nav.recent` มีรายการตามตาราง spec › Modules touched และชื่ออยู่บนสุดใต้ "ล่าสุด" ของหัวข้อนั้น (e2e)
- เปิดชิ้นที่สี่ → เหลือ 3; เปิดตัวเก่าซ้ำ → ขึ้นบนสุด ไม่ซ้ำ ชื่อปัจจุบัน (e2e)
- ไม่มีล่าสุด → ไม่มีหัวเล็ก "ล่าสุด" (e2e)
- `#/toon/series/{sid}/cast` → ไม่เขียน และล่าสุดของชุดนั้นถูกเน้น (e2e)
- ลบชุด → ชุดกับ EP ของมันหาย; ลบ EP บทเรียน หรือเพลง → หาย; `not_found` ของบทเรียนหรือเพลง → หาย (e2e)
- `localStorage` โยน JSON เสีย hash ผิดรูป หรือชื่อ 200 ตัว → ไม่มีรายการเสีย ชื่อตัดที่ 80 หน้าเปิดปกติ
- event `storage` จากแท็บอื่น → เมนูแสดงค่าใหม่
- `uv run pytest`, `typecheck`, `test`, `build` ผ่าน
