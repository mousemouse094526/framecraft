# 01: เมนูหลัก 5 หัวข้อ พร้อมขั้นและคลัง

**What to build:** ทุกหน้ามีหัวใหม่กับเมนูหลักเดียว: 5 หัวข้อใหญ่ ขั้นของสปอยและหน้าหลักของแต่ละหัวข้อ และส่วนคลัง กดครั้งเดียวถึง. จอ ≥1280px เมนูเป็น sidebar ตรึงซ้ายที่ยุบได้ จอแคบเปิดจากปุ่ม ☰ เป็น drawer. hash เดิมทุกตัวพาไปที่เดิม และแถบ tab เดิมหายไป.

**Blocked by:** None (can start immediately)

**Covers:**
- Decisions: D1, D2, D3, D4, D6, D7, D8, D9, D10 (โฟกัส, `inert`, leave guard, ค่ายุบ, ถอยกลับ), D11 (จุดตรึง 1280px, กฎรายการที่เปิดอยู่, ข้อความตำแหน่ง)
- Screens: เมนูหลักและหัวหน้า (ทุกหน้า)
- Seams: 1
- User stories: 1, 2, 4, 5, 6

**Status:** ready-for-agent

## Acceptance criteria

### เมนู

- hash ว่าง → "เมนูหลัก" มี ติดตั้ง แล้วหัวกลุ่ม สปอย การ์ตูนเล่า สอนกลอง แกะเพลง คลัง ตามลำดับ (e2e)
- ใต้สปอยมี "เลือกคลิป" "ตรวจแก้บท" "ผล render" พร้อมเลข 1–3; ใต้การ์ตูนเล่า "ชุดทั้งหมด" "สร้างชุดใหม่"; ใต้สอนกลอง "บทเรียนทั้งหมด"; ใต้แกะเพลง "เพลงทั้งหมด" (e2e)
- ส่วนคลังมี คลังคลิป คลังความรู้ คลังเสียง เสียงที่บันทึก พร้อมบรรทัด "ใช้กับ สปอย" หรือ "ใช้กับ สปอย, การ์ตูนเล่า" ตรงตัว (e2e)
- แต่ละแถวของ spec › Implementation › Hash → หน้านั้นเปิด รายการนั้น `aria-current="page"` หรือไม่มีตัวใด หัวกลุ่มนั้นเน้น ข้อความตำแหน่งตาม D11 (e2e)
- กดรายการ → hash ของรายการนั้น; back → hash ก่อน (e2e)

### ปุ่ม ☰

- จอแคบ: ปิดอยู่ก่อน; กดแล้วเปิด โฟกัสที่รายการที่เปิดอยู่ เนื้อหาหน้า `inert` (e2e)
- จอแคบ: เลือกรายการหรือ `Esc` → ปิด โฟกัสกลับปุ่ม; กดนอกหรือกดปุ่มอีกครั้ง → ปิด (e2e)
- จอกว้าง: เปิดอยู่ก่อน; กดปุ่ม → ยุบ ค่า `"true"` อยู่ใน `framecraft.nav.collapsed`; render ใหม่ยังยุบ; ค่าอื่น = เปิด; เลือกรายการไม่ยุบ (e2e)
- drawer เปิดแล้วจอข้ามเป็นกว้าง → drawer ปิด ใช้ค่ายุบ (e2e)
- leave guard ตอบยกเลิก → hash และหน้าเดิม drawer ปิด; ตอบตกลง → hash ใหม่ (e2e)

### ไม่พังของเดิม

- test เดิมที่หา "แถบ tab" หรือ "เมนู tab" เขียนใหม่ให้หา "เมนูหลัก" และ Log บอกว่าแก้อะไร (D8)
- `uv run pytest`, `typecheck`, `test`, `build` ผ่าน
- ตรวจมือที่ 1440, 1280, 1024, 375px ตาม spec › How success is judged
