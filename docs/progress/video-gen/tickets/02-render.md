# 02: render คลิปสอนกลอง

**What to build:** ผู้ใช้กด render ในหน้าแก้บทเรียน เห็นแถบ % ยกเลิกได้ แล้วได้ mp4 แนวตั้ง 1080×1920 ที่ชุดกลอง ไม้ เลนโน้ต และตัวนับขยับตรงกับเสียง พร้อม `.srt`. หน้าผล render เล่น โหลด ลบผลได้ และรายการบทเรียนบอกว่าบทเรียนไหนกำลัง render.

**Blocked by:** 01: ติดตั้งเสียงกลอง บทเรียน และฟังจังหวะ

**Covers:**
- Decisions: D3, D6 (พื้นหลังสีของแอป), D10 (ผล render), D12, D13 (ภาพ), D14, D17, D18, D21, D22 (ffmpeg ทาง stdin, ตัวหนังสือยาว, สถานะ render, `lesson_busy` ของลบ), spoil D36, toon D42, toon D45
- ADR: 0005, 0010, 0017, 0024, 0040, 0041
- Screens: ผล render ของบทเรียน, ส่วน render ของหน้าแก้บทเรียนกลอง, ป้าย render ในรายการบทเรียนกลอง
- Seams: 1 (render จน `done`, เสียงตรงภาพ, `too_long`, `busy`, `lesson_busy`, ยกเลิก, `ffmpeg_failed`), 2 (`frame_at`), 3 (render แล้วพาไปหน้าผล, ป้ายในรายการ)
- User stories: 3 (ชิ้นที่ไม่เน้นหรี่, ป้ายท่อน), 4, 5 (ผล render ทุกครั้ง)
- Legal: 2 (หัวเรื่องและบรรทัดรองแสดงชื่อเพลงและศิลปินบนจอ), 4 (วาดชุดกลองเองด้วยโค้ด)

**Status:** done

## Acceptance criteria

### ffmpeg ก่อน (prefactor)

- `h264_args(platform)` ใน `backend.ffmpeg` เลือก encoder ตาม spoil D36 และ `backend.spoil.trim` ใช้ตัวนี้; test ของ trim เดิมผ่านโดยไม่แก้
- `run_piped` ส่งเฟรมทาง stdin เช็ค `cancel` ก่อนทุกเฟรม; เขียนพังตอน `cancel` ตั้งอยู่ → `Cancelled`; เขียนพังไม่ได้ยกเลิก หรือ ffmpeg จบด้วย code ไม่ใช่ 0 → `FfmpegFailed` พร้อมบรรทัดท้ายของ stderr

### เฟรมและตัวหนังสือ

- ชุดกลองวาดด้วยรูปทรง Pillow ตามตำแหน่ง จุดกระทบ และจุดพักใน kit-sketch ไม่มีภาพจากคลิปอ้างอิง (legal ข้อ 4)
- เฟรมที่เวลาของโน้ต snare → พิกเซลที่จุดกระทบของ snare เป็นสีแดง; เฟรมก่อนหน้า 1/30 วินาที ไม่แดง
- ท่อนที่ `focus` = `["kick"]` → พิกเซลกลาง snare มืดกว่าในท่อนที่ไม่มี focus
- `frame_at` เวลาเดียวกันสองครั้ง → bytes เดียวกัน
- ช่วงหางเสียง → ภาพค้างที่ท่อนสุดท้าย ไม้อยู่จุดพัก
- `text.ass` มีหัวเรื่อง บรรทัดรอง ป้ายท่อนแทนหัวเรื่องตลอดท่อน (ท่อนแรกป้ายว่าง = หัวเรื่อง) ตัวนับ 1–4 คำบรรยาย ตัว L/R และเลขจังหวะ ตามตำแหน่งใน spec › Layout
- หัวเรื่องที่กว้างเกิน 860 px → ย่อด้วย `\fscx` บรรทัดเดียว; บรรทัดรองและคำบรรยายภาษาไทยยาว → ตัดคำไม่เกิน 2 บรรทัดด้วย `subtitles.cut_lines`
- `gate_rows.drums` = `drum_kit`, `font_kanit`, `ffmpeg`, `pythainlp`
- วัดเวลาต่อเฟรมบน Mac → เกิน 30 ms เลิกขยาย 2 เท่าของชิ้นที่ขยับ (D18); จดตัวเลขใน `progress.md`

### Render job

- `POST /render` แล้ว poll จน `done` → `renders/` มี mp4, srt, json; `ffmpeg -i` บอก 1080×1920, 30 fps, h264, aac, ความยาว `length_s` ± 0.1 วินาที
- **เสียงตรงภาพ:** บทเรียน snare ตัวเดียวกับ sample ปลอมที่เริ่มด้วยคลิก → sample แรกของเสียงใน mp4 กับเฟรมแรกที่จุดกระทบของ snare แดง ห่างไม่เกิน 1 เฟรม
- แถวใดของ `gate_rows.drums` ไม่ ok → `503` `not_ready` พร้อม `rows`
- บทเรียนยาวเกิน 90 วินาที → `422` `too_long`; ดิสก์ไม่พอ `length_s × 2 MB` → `507` `disk_full`
- render ซ้อน → `409` `busy` มี `lesson_id` ของงานที่รันอยู่
- ลบบทเรียนระหว่าง render ของมัน → `409` `lesson_busy`; `PUT` บทเรียนนั้นระหว่าง render → `200` และผลยังมาจากสำเนาตอนเริ่ม
- ยกเลิกกลางการส่งเฟรม → `cancelled` ไม่มี `.partial` เหลือ
- ตัวเลือกของ filter `ass` ผิด (`fontsdir` ที่ไม่มีอยู่ไม่ทำให้ ffmpeg จบ, D34) → `failed` `ffmpeg_failed` มีบรรทัดของ stderr ใน `message`
- start backend ใหม่ → `.render/` และ `.partial` หาย
- render บทเรียนเดิมสองครั้ง → `audio.wav` เหมือนกันทุก byte
- `GET /lessons/{id}/renders` เรียงใหม่สุดก่อน; โหลด `.mp4` และ `.srt` ได้; `DELETE` ผลที่ไฟล์เปิดอยู่ → `409` `in_use`
- รายการบทเรียนนับ `renders` ตามจริง; ลบบทเรียนลบผล render ทีละอันก่อน
- คลิป 30 วินาที render จบใน ≤ 60 วินาทีบน Mac Apple Silicon → จดเวลาใน `progress.md`
- คลิปอ้างอิง Smells Like Teen Spirit intro fill กรอกในแอปแล้ว render → เจ้าของดูเทียบกับคลิปอ้างอิงแล้วรับ (ผลจดใน `progress.md`)

### หน้าเว็บ

- render ในหน้าแก้ → บันทึกก่อน แถบ % และยกเลิก → `done` พาไป `#/drums/{id}/renders` และเลือกผลล่าสุด (e2e)
- เปิด `#/drums` ระหว่างงาน → แถวของบทเรียนนั้นมีป้ายพร้อม % (e2e)
- `failed` หรือ `cancelled` → ข้อความกับปุ่มลองอีกครั้ง (e2e)
- `busy` → บอกบทเรียนที่ render อยู่; ความยาวเกิน 90 วินาที → ปุ่ม render กดไม่ได้ (e2e)
- หน้าผล: player 9:16, โหลด mp4 และ `.srt`, ลบพร้อมยืนยัน; ว่าง → ข้อความว่ายังไม่เคย render; บทเรียนนี้กำลัง render → แถบ % ด้านบน (e2e)
- เปิดหน้าใดใต้ `#/drums` ที่ไม่ใช่หน้าที่เริ่มงาน → ไม่ถูกพาไปหน้าผลเมื่องานจบ
- หน้าตาตามแบบ Figma เมื่อ Blocked แถว design ของหน้าผล render ปิด; ก่อนนั้นใช้ component เดิมของแอป
