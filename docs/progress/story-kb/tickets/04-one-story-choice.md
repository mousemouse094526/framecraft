# 04: ค่าเลือก Story ของขั้น 1 เป็นค่าเดียว

**What to build:** ช่อง "เรื่องในคลังความรู้" ของขั้น 1 ทำงานเหมือนเดิมทุกอย่าง แต่สิ่งที่ผู้ใช้ทำกับช่องเก็บเป็นค่าเดียวที่มีสี่แบบ: ยังไม่แตะ (ตามเรื่องที่คลิปจำ), เลือกเรื่อง, เลือก "ไม่ใช้", และเรื่องที่ส่งไปถูกลบแล้ว. สถานะที่ขัดกันเอง (เรื่องถูกลบแต่ยังเลือกเรื่องอยู่) เขียนไม่ได้อีก.

**Blocked by:** 03: เรียบเรียงใหม่ใช้ Story ล่าสุด

**Covers:**
- Decisions: D3, D15
- Screens: ขั้น 1 ตั้งค่าคลิปสปอย: ช่อง Story
- User stories: 5

**Status:** done

## Acceptance criteria

- ยังไม่แตะช่อง แล้วเปลี่ยนคลิป → ช่องแสดงเรื่องที่คลิปใหม่จำไว้ หรือ "ไม่ใช้" (e2e)
- เลือกเรื่อง แล้วกดร่างบท → คำขอส่ง `story_id` ของเรื่องนั้น
- เลือก "ไม่ใช้" แล้วกดร่างบท → คำขอส่ง `story_id` เป็น `null`
- กดร่างบท แล้วได้ `story_not_found` → ช่องเป็น "ไม่ใช้" และแสดง "ไม่พบเรื่องนี้ในคลังความรู้แล้ว" (e2e)
- เห็นข้อความเรื่องถูกลบ แล้วเลือกเรื่องหรือเปลี่ยนคลิป → ข้อความหายไป (e2e)
- เปิดหน้าจาก order ที่มีเรื่อง → ช่องเริ่มจากเรื่องของ order (spoil-maker D87)
- ค่าเลือกเป็นค่าเดียวที่มีสี่แบบ; ค่าเลือกแยกกับธงเรื่องถูกลบไม่มีแล้ว (Blocked 8)
- test ของขั้น 1 ที่มีอยู่ผ่านโดยไม่แก้ค่าคาดหวัง
