# 01: play/pause ทุกจุด เล่นได้ทีละเสียง

**What to build:** ทุกจุดฟังเสียงทั้งแปดจุดเป็น `PlayButton` ไอคอน play/pause ที่เล่นผ่านเครื่องเล่นเสียงตัวเดียว: กดเสียงใหม่ = เสียงเดิมหยุด, กดปุ่มเดิม = หยุดชั่วคราวและเล่นต่อ. ปุ่มฟังจังหวะและฟัง reel บอก "กำลังผสมเสียง…" แล้วเป็น play/pause ไม่ผสมซ้ำถ้าค่าที่บันทึกไม่เปลี่ยน. ยังไม่มีเวลาบนปุ่ม (ticket 02).

**Blocked by:** None (can start immediately)

**Covers:**
- Decisions: D1, D2, D3, D4, D6, D7, D9, D10, D11, D12, D13 (ยกเว้นข้อเวลาและ media อื่น)

- Screens: `PlayButton` (component), เสียงพากย์ › ออกแบบเสียง, เสียงพากย์ › แถวเสียงที่บันทึก, ทำสปอย › การ์ดประโยค, ทำสปอย › เสียงพื้น, การ์ตูนเล่า › การ์ด (เสียงเล่า), คลังเสียง › แถวเสียง, reel กลอง › ฟังจังหวะ, reel cover › แถบทำ reel

## Acceptance criteria

### เครื่องเล่นเสียง

- กด A แล้วกด B → `pause` ของ A ก่อน `play` ของ B; A ชื่อ "ฟัง A" B ชื่อ "หยุดชั่วคราว B"
- กด A สามครั้ง → เล่น หยุดชั่วคราว เล่นต่อ โดยครั้งที่สามไม่ตั้ง `currentTime` เป็น 0
- B เล่นแล้วกด A → A เริ่มที่ `currentTime` 0
- `ended` หรือ `play()` reject ในรอบปัจจุบัน → ปุ่มกลับเป็น "ฟัง A" ไม่มีข้อความ
- `play()` ของ A reject ด้วย `AbortError` หลังกด B → B ยังเป็น "หยุดชั่วคราว B"
- ปุ่มที่เล่นอยู่ unmount, `src` เปลี่ยน หรือกลายเป็นกดไม่ได้ → เสียงหยุด
- test ทุกไฟล์เริ่มด้วยเครื่องเล่นว่าง (`resetPlayerForTests` ใน `test-setup.ts`)

### ปุ่มผสมเสียง

- กดฟังจังหวะสองครั้งไม่แก้อะไร → `POST …/listen` ครั้งเดียว ครั้งที่สองหยุดชั่วคราว
- แก้ Groove หรือค่าของ reel cover ขณะฟัง → เสียงหยุด ปุ่มพร้อมเล่น; กดต่อ → บันทึก ผสมใหม่ revoke URL เก่า
- ระหว่างผสม → ปุ่ม "กำลังผสมเสียง…" กดไม่ได้
- mount ใต้ `StrictMode` แล้วกด → wav เล่น
- ข้อปฏิเสธ offline และ save ล้มเหลว → เหมือนเดิม

### แปดหน้า

- ไม่มี `playAudio` หรือ `new Audio(` นอก `lib/player`; `lib/audio.ts` ถูกลบ
- ไม่มีปุ่มที่บนจอเป็นคำ "ฟัง" อย่างเดียว; ฟังจังหวะคงคำ, ปุ่มของ reel cover เป็น "ฟัง reel"
- test เดิมของแต่ละหน้าผ่านด้วยชื่อปุ่มใหม่ และยังพิสูจน์ URL ที่เล่น
- ปุ่มมีโฟกัสที่เห็น และสูง 44px ต่ำกว่า 640px
