# 02: เวลาบนปุ่ม และ media อื่นเล่นทีละตัว

**What to build:** ปุ่มเล่นแสดงเวลา `0:03 / 0:12` ขณะเล่นและหยุดชั่วคราว (ยังไม่รู้ความยาว = `0:03`). วิดีโอและเสียงเพลงในหน้าเพลงเข้ากฎทีละเสียง: เริ่มตัวหนึ่ง ตัวอื่นหยุดชั่วคราว โดยไม่แก้โค้ดตัวเล่นวิดีโอ.

**Blocked by:** 01: play/pause ทุกจุด เล่นได้ทีละเสียง

**Covers:**
- Decisions: D5, D8, D13 (ข้อเวลาและ media อื่น)
- ADR: 0072
- Screens: `PlayButton` (component)
- Seams: 1 (ข้อเวลาและ media อื่น)
- User stories: 4, 6

**Status:** ready-for-agent

## Acceptance criteria

- `timeupdate` ที่ 3.7 วิ `duration` 12 → ปุ่มแสดง `0:03 / 0:12`
- `duration` `NaN` หรือ `Infinity` → ปุ่มแสดง `0:03`
- หยุดชั่วคราว → เวลาค้าง; พร้อมเล่น → ไม่มีเวลา
- เวลาอยู่ใน `aria-hidden` ชื่อปุ่มไม่เปลี่ยนตามเวลา
- `play` event ของ `<video>` ที่ไม่ `muted` → เสียงของเครื่องเล่นหยุดชั่วคราว
- `<video muted>` เล่น → ไม่มีผล
- เครื่องเล่นเริ่มเสียง → `<video>`/`<audio>` ที่เล่นอยู่ถูก `pause`
- วิดีโอหนึ่งเริ่ม → วิดีโออื่นที่เล่นอยู่ถูก `pause`
