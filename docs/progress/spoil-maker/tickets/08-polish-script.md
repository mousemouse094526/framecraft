# 08: เรียบเรียงบท

**What to build:** บทที่ AI ร่างเล่าต่อกันเป็นเรื่องเดียว: หลังร่างบท AI อ่านบททั้งบทแล้วเรียบเรียงข้อความของแต่ละประโยคให้เชื่อมกัน ก่อนเลือก Shot. หน้าตรวจแก้มีปุ่ม "เรียบเรียงใหม่" ที่ทำขั้นเดียวกัน โดยประโยคที่ผู้ใช้แก้เองมีป้าย "แก้เอง" และคงไว้ เว้นแต่ผู้ใช้ติ๊กให้เรียบเรียงทับ. จำนวน ลำดับ บรรทัดที่อ้าง และ Shot ไม่เปลี่ยน.

## Acceptance criteria

### ขั้นเรียบเรียงใน Draft job

- คำสั่งร่างบทบอกว่าทุกประโยคเล่าต่อจากประโยคก่อนเป็นเรื่องเดียว
- Draft job `kind: "draft"` ผ่าน state `writing` → `polishing` → `matching`; คำสั่งเรียบเรียงมีสไตล์ `top_text` ทุกประโยคพร้อม `[{i}]` และบรรทัดที่อ้าง
- คำตอบจับคู่ด้วย `i`; `i` ผิดถูกทิ้ง; ตรวจต่อประโยค (±50%, ว่าง) และทั้งบท (ไม่ถึงครึ่ง, ความยาวรวม) ตาม spec › Draft job › เรียบเรียง; สั่งใหม่รวม 2 ครั้ง, timeout terminate แล้วเริ่มใหม่
- `kind: "draft"` ไม่ผ่านทั้ง 2 ครั้ง → ใช้ข้อความเดิมและไปต่อ; log ไม่มีข้อความบท
- `refs`, `shots`, `id`, `audio`, `top_text` ไม่เปลี่ยนจากการเรียบเรียง
- ค่าการสร้างข้อความแถว "เรียบเรียง" ตาม spec

### `edited` และเรียบเรียงใหม่

- `edited` ตามกฎ spec › Spoil draft (ต่างจากที่เก็บจริงเท่านั้น, แทรกเอง, ไม่มีฟิลด์ = `false`)
- `POST /draft-jobs` `{kind: "polish", include_edited?}` เช็คตามลำดับใน spec; `nothing_to_polish`, `invalid_request`, `no_draft`; ระหว่างงาน draft `locked` และคลิป `clip_busy`
- `include_edited` `false`: ประโยค `edited` เป็น fixed ข้อความไม่เปลี่ยน; `true`: ทุกประโยคเรียบเรียงและประโยคที่ถูกเรียบเรียง `edited` `false`
- ไม่ผ่าน 2 ครั้ง → `failed` `polish_failed` draft ไม่เปลี่ยน; `done` มี `done` = ประโยคที่เปลี่ยน
- ประโยคที่มีเสียงและข้อความเปลี่ยน → `stale_audio`
- ทุก test ใน spec › Seams 1 › เรียบเรียง ผ่าน

### หน้าตรวจแก้

- ปุ่ม "เรียบเรียงใหม่" เปิดกล่องเลือก: ช่องติ๊ก "เรียบเรียงประโยคที่แก้เองด้วย" (ตั้งต้นไม่ติ๊ก, แสดงเมื่อมีประโยคแก้เอง), คำเตือนเขียนทับเมื่อติ๊ก, คำเตือนต้องสร้างเสียงใหม่เมื่อมีประโยคที่มีเสียง
- กด "เรียบเรียง" รอการบันทึกประโยคที่ค้าง แล้วอ่าน `/draft` ใหม่ก่อนส่ง
- ระหว่างงาน "กำลังเรียบเรียง" กับปุ่มยกเลิก ช่องแก้กดไม่ได้; จบแล้ว "เรียบเรียง {n} ประโยค" หรือ "ไม่มีประโยคที่เปลี่ยน"; `polish_failed` → ข้อความใน spec
- ป้าย "แก้เอง" ที่ประโยค `edited`
- ตัวบอกขั้น (เมื่อ 07 เสร็จแล้ว หรือทำใน ticket ที่มาทีหลัง): "กำลังเรียบเรียง" และ "เรียบเรียงไม่สำเร็จ" ที่ขั้น 2
- หน้าตาตามแบบใหม่เมื่อ Blocked 15 เป็น `done`; ก่อนหน้านั้นใช้ component เดิมของ Script review ที่ 375 และ 1440
- ทุก test ใน spec › Seams 2 ข้อเรียบเรียง ผ่าน
