# 07: ตัวบอกขั้นบอกสถานะจริง

**What to build:** ตัวบอกขั้นของ tab สปอยไม่ดูเหมือนล็อกอีก: ทุกขั้นแสดงเลขและกดได้ ไม่มีเครื่องหมายถูกตามตำแหน่ง และใต้ชื่อแต่ละขั้นบอกสถานะจริง — EP ที่เลือก, กำลังร่างหรือจำนวนประโยค, render % หรือจำนวนคลิป — พร้อมจุดหมุนข้างขั้นที่มีงานรัน แม้เปิดขั้นอื่นอยู่.

**Blocked by:** 06: ตัด EP จากคลิปเดียว

**Covers:**
- Decisions: D68, D71 (ข้อตัวบอกขั้น)
- Screens: ตัวบอกขั้นของ tab สปอย — `pending` (Blocked 14), current [Figma: 3 tab](https://www.figma.com/design/pmdBVIP9xggk1wHCjdlKDZ/framecraft?node-id=8071-18633) component `Spoil steps`
- Seams: 2 (ตัวบอกขั้น)
- User stories: 15

**Status:** done

## Acceptance criteria

- ทุกขั้นเป็นลิงก์ที่มีเลข; ขั้นที่เปิดอยู่เด่นด้วย `aria-current="step"`; ไม่มีภาพเครื่องหมายถูก
- บรรทัดสถานะ: ขั้น 1 "{ชื่อคลิป} · EP {n}" หรือ "ยังไม่เลือก"; ขั้น 2 "กำลังร่าง" / "กำลังเลือกภาพ x/y" / "สร้างเสียง x/y" / "{n} ประโยค" / "ยังไม่มีบท"; ขั้น 3 "render {p}%" / "render…" / "render: สร้างเสียง x/y" / "{n} คลิป" / "ยังไม่มี"
- งานล่าสุด `failed` → "ร่างบทไม่สำเร็จ", "สร้างเสียงไม่สำเร็จ" หรือ "render ไม่สำเร็จ" ที่ขั้นของงานนั้น จนเริ่มงานใหม่
- จุดหมุนเฉพาะงานที่ state ไม่ใช่ `done`, `failed`, `cancelled`; `prefers-reduced-motion` ไม่หมุนแต่บรรทัดสถานะยังอยู่; มือถือแสดงชื่อเฉพาะขั้นที่เปิดแต่จุดหมุนแสดงทุกขั้น
- `SpoilMakerPage` เก็บ state ของ draft, renders และ `*/current` ร่วมกับทุกขั้น; หน้าที่เริ่มหรือยกเลิกงานแจ้งให้อ่านใหม่และเริ่ม poll ทุก 1 วินาที; งานจบ → อ่าน `/draft` และ `/renders` ใหม่
- render ระหว่างเปิดขั้น 1 → ขั้น 3 แสดง % และจุดหมุน; เปิดหน้าตอนไม่มีงานแล้วกด render ในขั้น 2 → ขั้น 3 เริ่มแสดง %
- หน้าตาตามแบบใหม่เมื่อ Blocked 14 เป็น `done`; ก่อนหน้านั้นต่อจาก component `Spoil steps` เดิม ที่ 375 และ 1440
- ทุก test ใน spec › Seams 2 › ตัวบอกขั้น ผ่าน
