# 09: ร่างบทแล้วรอที่ขั้นตรวจแก้

**What to build:** กดร่างบทแล้วแอปเปิดขั้น 2 ทันที เห็นการ์ดความคืบหน้าว่ากำลังร่างคลิปไหน EP ไหน อยู่ขั้นเขียนบท เรียบเรียง หรือเลือกภาพ และยกเลิกได้ตรงนั้น. ระหว่างร่าง ขั้น 1 แสดงค่าที่ส่งไปแบบอ่านอย่างเดียวจนงานจบหรือยกเลิก; ร่างล้มแล้วลองอีกครั้งหรือกลับไปแก้ตั้งค่าได้จากขั้น 2. การ์ดสไตล์มีบรรทัดอธิบายใต้ชื่อ.

**Blocked by:** None (can start immediately)

**Covers:**
- Decisions: D81, D82, D83, D84, D85, D86, D87 (และ D79 ส่วนขั้น 1 ที่เปลี่ยนตาม D82)
- ADR: 0010
- Screens: ตั้งค่าคลิปสปอย, หน้าตรวจแก้ ([Figma: Draft flow](https://www.figma.com/design/pmdBVIP9xggk1wHCjdlKDZ/framecraft?node-id=8083-27833)), ตัวบอกขั้นของ tab สปอย (บรรทัดสถานะขั้น 1 ระหว่างร่าง)
- Seams: 1 (Draft: `order`; Saved voice: `voice_in_use` ของงาน), 2 (ข้อ D81–D87)
- User stories: 5, 7, 14

**Status:** done

## Acceptance criteria

### API

- `POST /draft-jobs` `kind: "draft"` → `202` และ `GET /draft-jobs/current` มี `order` `{clip_id, clip_title, ep, style, layout, target_s, voice_id}` ตามคำขอ ทั้งระหว่างงานและหลัง `failed` หรือ `cancelled` จนมีงานใหม่
- Draft job `kind: "pick"` และ `"polish"` → `order` `null`
- `DELETE /voices/{id}` ของเสียงใน `order` ของ Draft job `kind: "draft"` ที่ยังไม่จบ → `409` `voice_in_use`; หลังงานจบ → `204`
- ทุก test ใน spec › Seams 1 ที่อ้าง D82 และ D87 ผ่าน

### ขั้น 2 ระหว่างร่างและหลังร่าง

- กดร่างบท (หรือร่างทับหลังยืนยัน) ได้ `202` → hash เป็น `#/spoil/review` และเห็นการ์ดความคืบหน้าทันที ไม่มี "ยังไม่มีบท" แวบขึ้น (e2e)
- current `writing` / `polishing` / `matching` 4/12 → การ์ดหัว "{ชื่อคลิป} · EP {n}" และขั้นที่กำลังทำตามลำดับ, "เลือกภาพ 4/12" (e2e)
- reload ขั้น 2 ระหว่างงาน → เห็นการ์ดเดียวกัน
- `done` ขณะเปิดขั้น 2 → เห็นบทใหม่; ขณะเปิดขั้นอื่น → ไม่ย้ายหน้า
- กดยกเลิก → "กำลังยกเลิก" ปุ่มกดไม่ได้ จน `cancelled` แล้วเปิดขั้น 1 ที่ค่าของ `order`; จบ `done` ก่อน → บทใหม่พร้อม "ยกเลิกไม่ทัน บทร่างเสร็จแล้ว"; `DELETE` ตอบ `404` → อ่าน current ใหม่ (e2e)
- `failed` → Alert error พร้อม "ลองอีกครั้ง" และ "กลับไปแก้ตั้งค่า" เหนือบทเดิมหรือ "ยังไม่มีบท"; มีบทเดิม → "ลองอีกครั้ง" ถามยืนยันร่างทับก่อนทุกครั้ง; ถูกปฏิเสธ → ข้อความใน Alert เดิมตาม spec › Frontend (e2e)
- poll ล้ม → offline แล้วกลับมาเอง; current หายระหว่างการ์ดแสดง → "งานหยุดกลางทาง"
- Alert ร่างล้มหายเมื่อเริ่ม Draft job ใหม่เท่านั้น

### ขั้น 1

- ระหว่าง Draft job `kind: "draft"` ยังไม่จบ → ทุกช่องแสดงค่าของ `order` และกดไม่ได้ ไม่มีปุ่มร่าง มี Alert info พร้อมลิงก์ไปขั้น 2 (e2e)
- คลิปของ `order` ไม่อยู่ในรายการแล้ว → เห็น `clip_title` ไม่มีรายการ EP; เสียงของ `order` ถูกลบ → "เสียงถูกลบแล้ว"
- หลัง `failed` หรือ `cancelled` → ค่าของ `order` ยังเลือกอยู่และแก้ได้ จนเริ่ม Draft job ใหม่
- `409` `busy` จากร่างบท → "มีงานร่างบทอยู่แล้ว" และขั้น 1 ล็อก
- การ์ดสไตล์ทั้ง 3 มีบรรทัดอธิบายตาม D84 ผูกกับ radio ด้วย `aria-describedby`
- ตัวบอกขั้นระหว่างร่าง: ขั้น 1 เป็น "{order.clip_title} · EP {n}"
- หน้าตาตาม frames `Spoiler setup / Draft flow …` และ `Script review / Draft flow …` ที่ 375 และ 1440
- ทุก test ใน spec › Seams 2 ที่อ้าง D81–D87 ผ่าน
